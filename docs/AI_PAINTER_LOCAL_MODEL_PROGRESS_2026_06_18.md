# AI-PET-WORLD 本地 AI Painter 小模型进度报告

日期：2026-06-18  
范围：纯自然家园底图，本地自研小模型训练  
状态：训练链路可运行，但尚未生成合格 MVP 世界图

## 1. 当前阶段定位

当前阶段不是程序化画图，也不是第三方在线绘图 API 接入。

当前工作是：在本地项目内训练自研小模型，让模型根据世界结构条件生成自然家园像素图。

本阶段只处理纯自然家园底图：

- 草地。
- 水体。
- 水岸。
- 自然道路。
- 树木。
- 岩石。
- 花草灌木。
- 空间深度。

本阶段不处理：

- 建筑。
- 角色。
- 动物。
- 昆虫。
- 管家。
- 城市。
- 动态层。

## 4. 当前判断

v4 和 v5 都没有达到目标。

v4 证明 PatchGAN 可以略微提升局部边缘，但仍然偏糊。

v5 证明离散调色板能提高边缘密度，但会带来颜色块和结构不稳定。

所以不能继续简单堆 epoch，也不能退回程序画图。下一步必须拆成更明确的自然局部结构任务。

v6 单类单样本已经候选通过，说明本地模型不是完全画不出，而是在多样本阶段缺少足够的外观条件和课程组织。
v7 同源小批量训练指标很好，但人工查看后发现 road/tree 等样本存在类别错标：例如 road 目标图实际是树冠。这个结果不能采纳，也不能说模型已经学会。
v8 增加了 target RGB 可见证据筛选，成功拒绝大量错标 patch，但训练后输出变糊，说明数据更真实后，当前模型容量与条件表达仍不足。
v9 在 v8 数据上加入类别 one-hot 条件和更强的局部细节 U-Net，但诊断结果退步：MAE 0.0935、PSNR 18.3136、锐度比 0.4411、边缘密度比 0.1872。训练脚本本来已经按草地、水体、水岸、道路、树木、岩石分别训练独立模型，因此 v9 证明“只加类别条件、只换更重模型”不是正确突破口。

v10 改成同源锁定课程训练：先用 v8 清洗后的数据，再让同一类别尽量从同一个 sourceId 里选择训练和验证。结果候选通过：MAE 0.0062、PSNR 39.5028、锐度比 0.9800、边缘密度比 0.9527。这个结果说明方向正确：不是退回程序画图，而是让本地小模型先在稳定视觉分布内学清楚，再逐步扩展到更多 sourceId。

v10 仍不是正式世界图。它只是局部 patch 候选通过，不能直接进入 `/world`。下一步必须把同源课程扩展成多源分级课程，并做局部合成验证。

v11 已完成真实训练：不再锁死单一 sourceId，而是每个自然类别最多选择 3 个 sourceId，并严格分离训练和验证样本。结果未通过：MAE 0.0648、PSNR 21.1268、锐度比 0.4901、边缘密度比 0.2026。这个结果说明当前模型在少量多源情况下仍会平均化，不能继续简单扩大 sourceId 数量。

v12 已完成真实训练：在 v11 多源课程数据基础上，额外把 sourceId 编码为稳定条件通道输入模型。它仍然是本地自研小模型训练，不是程序画图，也不是第三方绘图 API。诊断结果未通过：MAE 0.0647、PSNR 21.0328、锐度比 0.4741、边缘密度比 0.1949。这个结果说明仅靠 sourceId 条件不足以让模型保持不同来源的高频细节，下一步不能继续简单加 epoch，而要把训练拆成更强的“来源簇/视觉风格簇 + 局部类别 + 结构边界”组合课程。

v13 已完成来源专家路由：不再把多来源强行塞进同一个局部模型，而是把 v10 已候选通过的同源专家整理成 route-manifest。每个自然类别绑定明确 sourceId、checkpoint、target/generated、诊断指标。v13 不是完整世界图，也不是 ApprovedFrame；它的意义是把“同源专家可行”从实验结果升级为可被后续合成器调用的结构层。

v14 已完成单源完整图合成：选定 `natural-home-crop-v7-12-forest-stream-clean` 作为同一源图，在该源图内重新抽取草地、水体、水岸、道路、树木、岩石六类局部 patch，训练六类本地专家，再对完整 256x192 画面进行滑窗推理和 mask 分层合成。诊断结果候选通过：MAE 0.0495、PSNR 21.4323、锐度比 0.7798、边缘密度比 0.8644。v14 是当前第一张完整自然家园本地模型合成候选图，但还不能进入 `/world`，下一步需要更严格的整图 VisualJudge 和 ApprovedFrame 绑定。

## 6. 固定原则

- 训练图来自项目本地数据。
- 模型在本地训练和推理。
- 未过审图只能作为失败记录。
- 页面可以展示训练历史，但不能把失败图当正式世界图。
- `/world` 只展示 ApprovedFrame。
