本文件是 AI-PET-WORLD 后续执行的唯一计划表。后续开发、训练、审核、文档更新和代理协作，都必须先对照本文档。业务定义看 [业务说明](./BUSINESS_SPEC.md)，实时进度统一维护在 [当前进度表](./PROGRESS.md)。

除非项目所有者明确批准，任何人不得临时延伸、插入新模块、改变优先级、把后续模块提前、把实验结果说成正式结果，或把候选图绕过审核进入玩家世界。

## 固定执行纪律

| 规则 | 内容 |
|---|---|
| 唯一计划源 | 后续执行以本文档为准，README 只做入口和摘要 |
| 主线不跳跃 | 当前阶段没完成前，不进入后续阶段 |
| 不自由发挥 | 不允许因为技术上能做就临时加功能 |
| 扩展需申请 | 任何新增模块、改阶段、改目标、改验收标准，都必须先问项目所有者 |
| 先说明再执行 | 每次操作前说明当前阶段、要做内容、为什么做、完成标准 |
| 每轮有进度表 | 每次完成后打印当前进度表和下一步计划，进度文件统一维护在 `docs/PROGRESS.md` |
| 候选不等于正式 | 候选图、训练图、失败图、调试图都不能说成正式世界图 |
| `/world` 是主世界页 | `/world` 不是训练预览页，不允许展示局部图、crop 图、patch 图、tile 图、sprite 图或低于完整主世界帧尺寸的图 |
| 程序图不等于 AI 图 | 程序化绘制、SVG、Canvas、HTML、占位图只用于结构或调试，不是正式画面 |
| 本地小模型优先 | 当前视觉主线是本地自研 AI Painter 小模型，不接第三方在线绘图 API |
| 世界事实优先 | AI Painter 只负责视觉表达，不能篡改世界事实 |
| 没审核不展示 | 未通过 VisualJudge 和 ApprovedFrame 的图不能进入 `/world` |
| 训练全留档 | 成功图、失败图、打回图、候选图、资源账本、时间戳、耗时都必须自动保存 |

## 项目业务总主线

```txt
用户注册
-> 输入出生信息
-> 紫微斗数 / 人格映射
-> 管家灵魂、性格、沟通方式、长期偏好
-> 自主世界 Runtime
-> 世界事实 World Facts
-> Scene Blueprint / Condition Mask
-> 本地自研 AI Painter 小模型
-> 候选视觉输出
-> VisualJudge 审核
-> ApprovedFrame / RuntimeFrame
-> 玩家看到世界
```

长期目标：

```txt
管家自主行为
-> 管家自主建设世界
-> 世界规则生成自然、生态、地形、事件痕迹
-> 小镇 / 城市 / 多玩家管家共同世界逐步形成
-> AI Painter 把世界事实转成画面
-> VisualJudge 审核
-> 通过后展示给玩家
```

## 当前 MVP 总目标

当前 MVP 只做一件事：

```txt
让本地自研 AI Painter 小模型稳定生成“纯自然家园静态视觉底座”，
并通过 VisualJudge，最终形成可进入 /world 的 ApprovedFrame。
```

当前允许内容：

| 类型 | 是否允许 | 说明 |
|---|---:|---|
| 草地 | 是 | 自然家园底色和地表变化 |
| 水体 | 是 | 河流、池塘、水面 |
| 水岸 | 是 | 水体与地面交界 |
| 自然小路 | 是 | 土路、小径，不是城市道路 |
| 树木 | 是 | 自然树、森林边界 |
| 岩石 | 是 | 石块、山石、岸边石 |
| 花草灌木 | 是 | 细节、自然层次 |
| 空间深度 | 是 | 前中远景、景深、遮挡 |

当前禁止混入：

| 类型 | 当前处理 |
|---|---|
| 建筑 | 禁止进入当前自然家园训练 |
| 房屋 | 禁止进入当前自然家园训练 |
| 建筑地基 | 禁止进入当前自然家园训练 |
| 墙体 / 屋顶 | 禁止进入当前自然家园训练 |
| 施工材料 | 禁止进入当前自然家园训练 |
| 管家 | 后续人物 / 管家 VisualUnit |
| 人物 | 后续人物 VisualUnit |
| 动物 | 后续动物 VisualUnit |
| 昆虫 | 后续生态 / 动效 VisualUnit |
| 小镇 / 城市 | 后续建设系统和 Runtime 合成 |

## AI Painter 执行分线

后续训练和页面入口必须分清两条线，不能混在一起。

| 分线 | 当前作用 | 当前状态 | 页面入口要求 |
|---|---|---:|---|
| 完整训练线 | 训练完整自然家园画面，服务第一张正式 ApprovedFrame | 当前主线 | 从训练主页进入“完整训练入口” |
| 局部训练线 | 训练树、水、草、石、人物、建筑、状态帧等 VisualUnit | 后置 | 从训练主页进入“局部训练入口”，但不能抢主线 |

当前只允许推进完整训练线：

```txt
完整自然家园数据
-> 完整 Scene Blueprint / Condition Mask
-> 完整候选图
-> VisualJudge
-> 完整 ApprovedFrame
```

局部训练线只能保留入口、数据契约和历史素材查看，不允许把局部图、crop 图、tile 图或 sprite 图写入 `/world`。

后期 Runtime 不靠单张巨大 PNG 运行，而是：

```txt
完整世界构图能力
+ 局部视觉单元
+ 动态状态帧
+ 世界事实 Runtime
-> RuntimeFrame
-> 审核后展示
```

## 阶段 B：自然家园小模型训练

阶段 B 完成标准：

```txt
本地小模型生成
AND 内容只包含自然家园允许内容
AND 响应 Blueprint / Mask
AND 不模糊、不严重伪影、不大面积坏结构
AND 候选、失败、资源、耗时自动归档
```
