本文档是 AI-PET-WORLD 后续执行的唯一计划表。后续开发、训练、审核、文档更新和代理协作，都必须先对照本文档。

除非项目所有者明确批准，任何人不得临时延伸、插入新模块、改变优先级、把后续模块提前、把实验结果说成正式结果，或把候选图绕过审核进入玩家世界。

## 0. 固定执行纪律

| 规则 | 内容 |
|---|---|
| 唯一计划源 | 后续执行以本文档为准，README 只做入口和摘要 |
| 主线不跳跃 | 当前阶段没完成前，不进入后续阶段 |
| 不自由发挥 | 不允许因为技术上能做就临时加功能 |
| 扩展需申请 | 任何新增模块、改阶段、改目标、改验收标准，都必须先询问项目所有者 |
| 先说明再执行 | 每次操作前必须说明：当前阶段、要做内容、为什么做、完成标准 |
| 每轮有进度表 | 每次完成后必须打印当前进度表和下一步计划 |
| 候选不等于正式 | 候选图、训练图、失败图、调试图都不能说成正式世界图 |
| 程序图不等于 AI 图 | 程序化绘制、SVG、Canvas、HTML、占位图只能用于结构或调试，不是正式画面 |
| 本地小模型优先 | 当前视觉主线是本地自研 AI Painter 小模型，不接第三方在线绘图 API |
| 世界事实优先 | AI Painter 只负责视觉表达，不能篡改世界事实 |
| 没审核不展示 | 未通过 VisualJudge 和 ApprovedFrame 的图不能进入 `/world` |
| 训练全留档 | 成功图、失败图、打回图、候选图、资源账本、时间戳、耗时都必须自动保存 |

## 1. 项目业务总主线

AI-PET-WORLD 的业务主线不是“画一张图”，而是让一个自主世界逐步变成可视、可审、可运行的游戏世界。

```txt
用户注册
-> 输入出生信息
-> 紫微斗数 / 人格映射
-> 管家灵魂、性格、沟通方式、长期偏好
-> 自主世界 Runtime
-> 世界事实 World Facts
-> Scene Blueprint / Condition Mask
-> 本地自研 AI Painter 小模型
-> 候选视觉输出
-> VisualJudge 审核
-> ApprovedFrame / RuntimeFrame
-> 玩家看到世界
```

长期目标：

```txt
管家自主行为
-> 管家自主建设世界
-> 世界规则生成自然、生态、地形、事件痕迹
-> 小镇 / 城市 / 多玩家共同世界逐步形成
-> AI Painter 把世界事实转成画面
-> VisualJudge 审核
-> 通过后展示给玩家
```

## 2. 当前 MVP 总目标

当前 MVP 只做一件事：

```txt
让本地自研 AI Painter 小模型稳定生成“纯自然家园静态视觉底座”，
并通过 VisualJudge，最终形成第一张可进入 /world 的 ApprovedFrame。
```

当前允许画面内容：

| 类型 | 是否允许 | 说明 |
|---|---:|---|
| 草地 | 是 | 自然家园底色和地表变化 |
| 水体 | 是 | 河流、池塘、水面 |
| 水岸 | 是 | 水体与地面交界 |
| 自然小路 | 是 | 土路、小径，不是城市道路 |
| 树木 | 是 | 自然树、森林边界 |
| 岩石 | 是 | 石块、山石、岸边石 |
| 花草灌木 | 是 | 细节、自然层次 |
| 空间深度 | 是 | 前中远景、景深、遮挡 |

当前禁止混入：

| 类型 | 当前处理 |
|---|---|
| 建筑 | 禁止进入当前自然家园训练 |
| 房屋 | 禁止进入当前自然家园训练 |
| 建筑地基 | 禁止进入当前自然家园训练 |
| 墙体 / 屋顶 | 禁止进入当前自然家园训练 |
| 施工材料 | 禁止进入当前自然家园训练 |
| 管家 | 后续人物 / 管家 VisualUnit |
| 人物 | 后续人物 VisualUnit |
| 动物 | 后续动物 VisualUnit |
| 昆虫 | 后续生态 / 动效 VisualUnit |
| 小镇 / 城市 | 后续建设系统和 Runtime 合成 |



VisualUnit 重新启动条件：

```txt
阶段 B 自然家园小模型可生成稳定候选
AND 阶段 C VisualJudge 能拦截失败图

```

不满足以上条件，不继续 VisualUnit judge、人物、建筑、动态帧。

## 14. 阶段 J：Runtime 动态合成

目标：不是生成一张死图，而是让世界事实驱动画面组合。

```txt
World Facts
-> Runtime object states
-> VisualUnit state frames
-> AI Painter / local model visual expression
-> VisualJudge
-> RuntimeFrame
-> Player view
```

| 任务 | 说明 |
|---|---|
| 地表层 | 自然家园底座 |
| 对象层 | 树、石、设施、人物、管家 |
| 状态层 | 建造中、损坏、成长、流动 |
| 动效层 | 水流、树叶、天气 |
| 审核层 | 每个画面或关键帧都受 VisualJudge 控制 |

## 15. 阶段 K：管家自主建设世界视觉化

目标：让管家的自主行为真正改变世界画面。

```txt
管家产生动机
-> 选择建设计划
-> 世界事实更新
-> 视觉系统生成变化
-> VisualJudge 审核
-> 玩家看到建设痕迹
```

| 内容 | 要求 |
|---|---|
| 管家不受玩家直接控制 | 玩家通过手机建议，管家可参考但不服从 |
| 建设必须来自世界事实 | 不能由画面系统凭空增加 |
| 视觉只表达事实 | 不改写 Runtime |
| 阶段变化可追踪 | 从地基到完成都要有状态 |
