# 条件图到RGB模板收敛防护规范

更新时间：2026-08-01 19:45:00 +08:00

## 1. 问题定义

条件包彼此不同，不代表图像生成器一定会输出不同的RGB构图。生成器可能把不同水文条件压缩成同一种“纵向主河＋中部河岛或分汊”的视觉模板。旧流程在出图前只比较条件图，生成后才比较历史RGB，因此无法在消耗生成次数前发现这种跨阶段模板收敛。

## 2. 新的出图前硬门禁

- 有水条件在生成前必须提取64×48水体布局和32×32位置、尺度归一化水体形状。
- 程序只为审核读取历史完整地图RGB并提取同结构签名；历史RGB像素、文件路径和匹配记录不得写入生成提示词或传给图像生成器。
- 候选条件水体与历史RGB水体在直接、水平镜像、垂直镜像和180度旋转四种关系中，任一达到合同阈值即停止出图。
- 本门禁与条件图对条件图、64组2016对、道路入口、水文端口和生成后RGB审核同时生效；任何旧门禁不得降低。

## 3. 当前第45与第49张

- 第45张继续固定：`wet-season-drainage-hollow`、湿季、内陆水文、东侧道路入口。
- 第49张继续固定：`wet-season-drainage-hollow`、湿季、内陆水文、西侧道路入口。
- 两张都必须有北侧上游入口、南侧下游出口及相邻区域成对水口。
- 重新选择的测量窗口必须来自既有Sakaerat / Wang Nam Khiao正式泰国测量候选包，同时通过跨模态历史RGB水体门禁。
- 旧v3和v4失败图只用于审核签名，不得作为ImageGen参考图；不得自动重试。

## 4. 输出边界

本规范授权条件算法、审核算法、测量窗口重选和项目所有者本次明确要求的两张替换RGB。它不授权GPU训练、RuntimeFrame或进入`/world`。
