# 条件图到 RGB 模板收敛防护规范

## 1. 问题定义

条件包彼此不同，不代表图像生成器一定输出不同的 RGB 构图。生成器可能把不同道路、水文、岸线和分区压缩成同一个视觉模板，因此必须在生成前比较“候选条件结构”与“历史 RGB 结构”，并在生成后再次审核 RGB。

## 2. 生成前跨模态门禁

- 从候选条件提取道路、水体、岸线、分区和整体骨架签名。
- 审核器只为结构比较读取历史完整地图 RGB；历史像素、路径和匹配记录不得进入提示词或传给生成器。
- 直接、水平镜像、垂直镜像和 180 度旋转任一关系达到正式阈值时，停止出图并保存无图阻断。
- 比较范围覆盖全部成功、待审、机器失败和 Owner 拒绝历史，不得只比较当前批次或相同槽位。
- 条件对条件、条件对历史 RGB、道路边界、水文端口和生成后 RGB 审核同时生效，任何一层不得替代其他层。

## 3. 生成后门禁

- 从实际 RGB 重新提取结构，不能直接信任条件签名。
- 使用与生成前一致的归一化、变换集合和阈值。
- 分别记录条件结构相似、RGB 结构相似、条件响应偏差和未知模板坍缩。
- 命中历史模板时保存真实失败图、相似记录身份、指标和失败码；不得自动换 seed、重试或降低阈值。

## 4. 数据与授权边界

重新选择的测量窗口必须来自当前区域的正式来源候选包，并同时通过来源、条件唯一性和跨模态历史 RGB 门禁。旧失败 RGB 只用于审核签名，不能作为生成参考。

本文定义算法和审核边界，不授权测量窗口变更、RGB 生成、训练、验证、RuntimeFrame 或 `/world`。具体样本和运行结论只保存在机器证据中。
