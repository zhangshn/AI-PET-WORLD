# 紫微斗数数据字典 P36-H-7 格局可读性复核

## 模块定位

本文件对应 P36-H-7，用来固定格局解释的两层边界：

1. 总字典只解释格局本身，包括成格条件、破格条件、加吉加煞、常见读法、资料来源和误用边界。
2. 当前盘只解释这张盘真实命中的格局，包括命中证据、盘层、宫位、三方四正、四化来源、是否破格和是否需要复核。

这一步不做页面细节，不做行为映射，不做人格化分析。它只解决一个核心问题：当前盘右侧或弹窗里只能显示盘中真实命中的格局；没有命中的格局保留在总字典，不进入当前盘结果。

## 八类格局复核范围

| 类别 | 用途 | 当前盘显示规则 |
|---|---|---|
| 文曜辅佐吉格 | 解释文昌、文曲、魁钺、左右、化科等文曜辅佐结构 | 只有命中后才显示，必须写明文曜如何辅助主星、宫位和三方四正 |
| 主星骨架格局 | 解释主星组合形成的命盘主轴 | 优先于杂曜细节，但必须同时接受煞忌、四化和庙旺落陷修正 |
| 禄马权科资源格局 | 解释禄、马、权、科等资源、行动、权责和名誉结构 | 必须说明资源从哪里来、落在哪个宫、是否能承接 |
| 煞曜压力格局 | 解释羊陀火铃、空劫、化忌等压力结构 | 只写压力来源、受压主题、制化和复核，不写恐吓式断语 |
| 杂曜细节格局 | 解释红鸾天喜、台辅封诰、孤寡哭虚等细节结构 | 只能补充主星和宫位，不覆盖主轴 |
| 凶格破格 | 解释煞忌、落陷、空劫、纠缠和破耗机制 | 必须说明破坏对象、证据、是否制化和修复路径 |
| 动态盘触发格局 | 解释大限、流年、流月、流日、流时触发 | 必须保留上层背景，不能用流年改写大限或原盘 |
| 待复核格局 | 保留资料缺口、规则缺口和样例缺口 | 不进入当前盘结论，只进入复核队列或资料字典 |

## 十二个必备解释段

| 段落 | 作用 |
|---|---|
| 总字典边界 | 说明这条资料只解释格局本身，不代表任何命盘已经命中 |
| 当前盘边界 | 说明当前盘只解释真实命中的格局 |
| 命中证据 | 必须有 patternId、conditionText、matchedPalaces、sourceRuleIds 和盘层证据 |
| 成格解释 | 说明为什么成立、哪颗星参与、哪个宫承接 |
| 破格解释 | 说明哪里被煞忌、落陷、空劫、冲破或资料不足影响 |
| 加吉增强 | 说明禄权科、魁钺左右、昌曲等如何增强 |
| 动态盘层级 | 区分原盘、大限、流年、流月、流日、流时 |
| 当前盘输出 | 规定当前盘怎么写成自然语言段落 |
| 隐藏规则 | 没有命中、证据不足、盘层未启用、待复核时隐藏 |
| 可读性检查 | 检查是否把总字典、当前盘、同宫、会照和三方四正混在一起 |
| 资料不足处理 | 缺来源、缺样例、缺规则、缺盘层时降级或进入复核 |
| 复核备注 | 标记需要抽查盘例或补来源的位置 |

## 当前盘输出规则

当前盘格局结果必须按以下顺序输出：

1. 先写盘层：原盘、大限、流年、流月、流日或流时。
2. 再写格局名称和命中宫位。
3. 再写命中证据：参与星曜、同宫、对宫、三方四正、四化来源和 sourceRuleIds。
4. 再写成色：成格、破格、加吉、加煞、降权、待复核。
5. 最后写边界：这只是当前盘命中结果，不复制总字典全文。

没有命中的格局不显示；待复核格局不显示为命盘结论；动态盘只显示当前选中盘层的线索，同时保留上层背景。

## 验收结论

本合同把“格局总字典”和“当前盘命中格局”拆开。总字典负责沉淀完整资料，当前盘负责筛出真实命中的结果并给出证据链。

这能解决当前最关键的解释混乱：不能因为字典里有某个格局，就在命盘里显示它；也不能把格局本身的通用解释，直接当成这张盘的结论。
