# 紫微斗数后续路线图

更新日期：2026-07-05

## 总原则

1. 先闭合紫微斗数资料和算法，再考虑行为映射。
2. 参数、枚举、规则表只定义一次，其他模块调用。
3. 页面只读取 API / ViewModel，不直接改底层算法。
4. 公版古籍可存原文、术语、篇目和自有摘要；现代资料只做来源索引和人工复核，不复制正文、截图、商标、图标或成套表达。
5. 每个阶段完成后必须更新 `EXECUTION_TABLE.md`。

4. 来源引用已经覆盖 22 个实际业务资料层和 2938 条带来源引用资料。

6. 12 个后续扩充项已经排入优先级队列。
