# 紫微斗数读盘调用链

更新日期：2026-07-05

## 总原则

读盘调用链必须按照紫微斗数资料层级走，不做自由发挥，不先做人格化分析。

当前盘分析的顺序是：先排盘，再取资料，再合证据，最后输出解释。

```txt
排盘结果
  -> 基础实体
  -> 星曜本体
  -> 星曜入宫
  -> 同宫与对宫
  -> 三方四正
  -> 四化与庙旺落陷
  -> 格局命中与破格
  -> 动态盘层级
  -> 专题合并
  -> 当前盘解释
```

## 第一步：读取原盘

先读取原盘的出生资料、命宫、身宫、十二宫、主星、辅曜、煞曜、杂曜、庙旺落陷、本命四化和原盘格局。

原盘是所有动态盘的底盘。后续大限、流年、流月、流日、流时都不能删除原盘，只能在原盘基础上叠加分析。

## 第二步：确定命身和宫线

命身结构是读盘入口。

| 内容 | 读法 |
|---|---|
| 命宫 | 看基础结构、主轴、长期承担方式 |
| 身宫 | 看后天落点、行动重心、实际承接处 |
| 命迁线 | 看自我和外部环境如何互相牵动 |
| 财官线 | 看资源、事业、执行和结果 |
| 夫妻福德线 | 看关系互动和内在满足 |
| 父母疾厄线 | 看支援、压力、身体状态和来源 |

这个阶段只建立骨架，不急着输出结论。

## 第三步：读取星曜本体

对每个宫先看主星，再看辅曜、煞曜、杂曜和周期星。

| 顺序 | 原因 |
|---|---|
| 主星 | 决定该宫主调 |
| 辅曜 | 判断支援、修饰、贵助、文名 |
| 煞曜 | 判断压力、阻滞、破耗、冲突 |
| 杂曜 | 补细节、特殊主题、边界和触发点 |
| 周期星 | 只在对应动态层级使用 |

四化不是普通星曜，不能按普通星曜显示庙旺。四化必须说明来源天干、目标星和盘层。

## 第四步：转换成入宫解释

星曜本体必须经过宫位转换才能进入当前盘解释。

例如：

| 层级 | 读法 |
|---|---|
| 贪狼本体 | 欲望、社交、才艺、资源流动、变化 |
| 贪狼入夫妻 | 关系吸引、互动欲望、关系资源、变化成本 |
| 贪狼入财帛 | 收入机会、消费欲望、资源流动、偏财和风险 |
| 贪狼入官禄 | 工作变化、表现欲、应酬资源、职业转向 |

如果没有入宫转换，只用星曜本体解释某个盘，会显得空泛。

## 第五步：合并同宫

同宫关系权重最高。

同宫解释要判断：

1. 哪颗星是主轴。
2. 哪颗星是辅助。
3. 哪颗星在推动。
4. 哪颗星在制造压力。
5. 哪颗星在修复。
6. 是否有四化触发。
7. 是否有煞忌破坏。

同宫不是星曜解释相加，而是同一宫位主题下的混合结构。

## 第六步：读取对宫

对宫用于看照见、拉扯、对象和外部反馈。

例如夫妻宫看关系时，对宫官禄会带入责任、职业状态和外部压力；命宫看自我时，对宫迁移会带入外部环境和行动场景。

对宫不能替代本宫，但会明显改变本宫解释。

## 第七步：读取三方四正

三方四正用于看结构。

| 三方四正读法 | 说明 |
|---|---|
| 会吉 | 结构支援增强，主题更容易落地 |
| 会煞 | 结构压力增强，主题有阻力或代价 |
| 会禄权科 | 资源、权责、名誉或修饰被触发 |
| 会忌 | 牵挂、阻滞、反复和修复成本增加 |
| 会空劫 | 落空、虚耗、断裂或非稳定结构 |

三方四正是判断格局成色、宫位强弱和当前盘综合解释的关键。

## 第八步：读取状态修正

状态修正必须跟着星曜和宫位走。

| 状态 | 使用方式 |
|---|---|
| 庙旺落陷 | 修正星曜发挥顺逆，不直接定吉凶 |
| 四化 | 看来源、目标、宫位和盘层 |
| 吉曜 | 增加支援、修饰、名位、贵助 |
| 煞曜 | 增加压力、冲突、破耗、突发 |
| 空劫 | 增加落空、虚耗、断裂 |
| 禄马 | 增加资源移动和行动变化 |
| 桃花 | 增加吸引、人际、关系和欲望主题 |

状态修正不能单独输出结论，必须回到宫位和星曜。

## 第九步：读取格局

格局必须由格局算法命中，不能因为字典里有这个格局就显示。

当前盘格局解释要按这个顺序：

1. 格局名称。
2. 当前盘是否命中。
3. 命中宫位。
4. 核心星曜。
5. 成格证据。
6. 加吉证据。
7. 加煞证据。
8. 破格证据。
9. 当前盘成色。
10. 动态盘是否触发。
11. 解释边界。

总格局字典解释格局本身；当前盘格局解释这张盘为什么这样论。

## 第十步：读取动态盘

动态盘必须保留继承链。

```txt
原盘
  -> 大限
  -> 流年
  -> 流月
  -> 流日
  -> 流时
```

| 选择状态 | 页面和解释应该显示 |
|---|---|
| 未选择 | 原盘命宫、原盘十二宫、原盘格局 |
| 选择大限 | 原盘底盘 + 大限命宫 + 大限十二宫 + 大限格局 |
| 选择流年 | 原盘底盘 + 大限标记 + 流年命宫 + 流年十二宫 + 流年格局 |
| 选择流月 | 原盘底盘 + 大限标记 + 流年标记 + 流月命宫 |
| 选择流日 | 继续保留上层标记，并增加流日触发 |
| 选择流时 | 继续保留上层标记，并增加流时微调 |

再次点击同一个大限或同一个流层选择时，回到上一级或原盘状态。

## 第十一步：生成专题解释

专题解释从盘面证据合并，不从单条资料直接生成。

| 专题 | 证据来源 |
|---|---|
| 命身 | 命宫、身宫、命迁线、主星、三方四正 |
| 事业 | 官禄、迁移、财帛、命宫、四化、格局 |
| 财务 | 财帛、田宅、福德、官禄、禄马、化禄化忌 |
| 感情 | 夫妻、福德、命宫、迁移、桃花、煞忌 |
| 家庭 | 父母、兄弟、子女、田宅、相关四化 |
| 健康 | 疾厄、命宫、父母、煞忌、动态触发 |
| 迁移 | 迁移、命宫、天马、四马地、流年流月 |
| 风险 | 煞曜、化忌、空劫、破格、不良格局 |

专题解释要写“证据如何汇合”，不能写成现代人格标签。

## 第十二步：输出当前盘解释

每段当前盘解释都使用固定结构。

| 段落 | 内容 |
|---|---|
| 结论 | 只写当前盘证据能支持的判断 |
| 主证据 | 星曜、宫位、格局、四化、亮度 |
| 关系证据 | 同宫、对宫、三方四正、夹宫 |
| 动态证据 | 原盘、大限、流年、流月、流日、流时 |
| 增强信号 | 哪些星曜、四化、宫位关系增强 |
| 削弱信号 | 哪些煞忌、空劫、破格削弱 |
| 复核边界 | 哪些资料仍需校验，哪些不能断死 |

没有证据的内容不输出。没有在盘中出现的格局不输出。未复核资料不进入当前盘解释正文。
