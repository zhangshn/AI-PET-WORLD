# 紫微斗数页面与验收

更新时间：2026-08-03 09:23:45 +08:00

状态：active-page-acceptance-contract

不允许自由发挥；除非发现错误导致无法继续，必须先停下来询问项目所有者。


## 页面目标

`/ziwei` 页面用于展示紫微斗数排盘、动态盘、格局、星曜字典和详细分析。

页面不负责：

1. 重新计算星曜。
2. 重新定义参数。
3. 重写四化、庙旺落陷或动态盘算法。
4. 输出未命中的格局。
5. 复制外部软件布局或文案。

## 主盘验收

1. 十二宫外圈布局正确。
2. 中宫展示出生信息、命身宫、当前查看盘层和摘要。
3. 主星横向展示，辅曜、煞曜、杂曜、长生十二神等按紧凑方式展示。
4. 命宫、身宫、原命、大限命、流年命、流月命、流日命、流时命等标记按当前选择显示。
5. 三方四正线条只显示当前查看盘层，不混用。

## 宫格密度规则

1. 宫格主盘完整展示本宫星曜，主星、辅曜、煞曜、杂曜、长生十二神、年系星曜、月系星曜、日时系星曜不得被隐藏。
2. 不得用 +N 折叠主盘星曜；主盘星曜必须按类别分行横向排列，避免杂曜被挤出宫格。
3. 主星和杂曜在宫格中横向排列，主星用更高字号和红色权重，辅曜用蓝色，煞曜和四化用红色，杂曜用青绿色，流曜用橙色。
4. 动态命宫标记、动态十二宫标记和动态飞星可以使用轻量文字标识；当流层证据过多时，只允许动态流曜层做数量保护，不能影响原盘主盘星曜。
5. 三方四正动态线条必须弱化透明度，不应压住宫内星曜文字。
6. 宫格直接显示格局指标条，至少要能看到该宫命中格局数量，并用颜色区分破格和不良格局风险。

## 流动时间验收

1. 默认进入原盘状态。
2. 点击同一个大限应取消选择并回到原盘。
3. 选择流年时保留大限层级，不删除上级证据。
4. 流月、流日、流时以此类推。
5. 下级流层只追加短周期触发和降权说明。

## 分析验收

1. 格局面板只显示盘中命中的结果。
2. 原盘、大限、流年、流月、流日、流时的格局要分层标注。
3. 不良格局和破格必须显示，但要有边界和复核提示。
4. 星曜解释弹窗应先显示通用星曜解释，再显示入宫、组合和当前盘解释。
5. 数据字典是数据字典，当前盘解释是当前盘解释，两者必须分开。

## 适配与数据边界

桌面端是主验收视口；响应式适配不得改变排盘、盘层、星曜、格局和证据语义。页面只读取正式结构化数据与命中结果，不重新计算规则，不绕过 `page-view` 和资料一致性检查。
