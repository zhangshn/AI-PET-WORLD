## 可存储边界

1. 公版古籍可以存原文、术语、篇目、版本、主题索引和项目自有摘要。
2. 不复制第三方软件截图、图标、商标、排版或成套文案。
3. 现代书籍内容暂不采集，只存书名、作者、版本、页码、主题、链接和复核状态。
4. 网站、视频、课程、论坛资料只存元信息和项目自有摘要，不存整篇正文或字幕全文。
5. 人工样例不能把单一样例写成通用理论。
6. 参考图只用于人工验收和布局方向，不照搬外部产品。

## P35-B 晋级规则

1. 任何资料必须先有来源记录，再进入片段槽。
2. 公版古籍正文必须能确认版本或来源，不能把现代点校本正文当成公版原文。
3. 现代书籍、网站、视频、软件、论坛和大学图书馆馆藏目录先停留在元信息层，只有项目自有摘要、馆藏索引和结构化标签可以继续流转。
4. 大学图书馆馆藏目录不能直接当正文来源；确认公版古籍正文后再转入公版古籍正文层。
5. 论坛和人工样例必须脱敏，单一样例只能作为校验线索。
6. 与硬规则冲突的资料进入复核队列，不直接覆盖星曜、格局、四化、庙旺或动态盘规则。

## P35-C 清洗结果边界

真实资料采集批次必须沿用 P35-A 到 P35-F 的来源、清洗、主题映射、入库门禁和页面可见性规则。P35-C 固定规则如下：

1. 公版古籍可以存原文、术语、篇目、版本、主题索引和自有摘要。
2. 现代资料只存元信息和复核状态。
3. 现代资料不得复制正文、截图、图标、商标、排版或成套表达。
4. 全网采集必须先进入来源登记表，再进入片段槽和主题映射。
5. 来源不明或不可确认的现代资料不得进入解释正文。
6. 清洗结果必须输出 `dedupKey`、`entityRefs`、`conflictSignalIds`、`reviewQueueId`、`promotionStatus`。
7. `blocked` 结果必须有阻断原因，不能进入数据字典层。
8. `ready-for-dictionary` 结果必须指定目标数据字典层。

## P35-D 主题映射边界

P35-D 负责把已清洗资料映射到数据字典主题，不负责改排盘算法，也不负责直接生成当前盘解释。主题包括：

1. `star`：星曜本体、分类、别名、亮度引用。
2. `palace`：十二宫位、宫位主题链和字段。
3. `branch`：十二地支、四马地等地支组和空间语境。
4. `stem`：十天干、阴阳五行和四化来源引用。
5. `element-gate`：五行局和局数解释。
6. `pattern`：格局、成格、破格、修复信号。
7. `transformation`：四化主题、目标星和所属流层。
8. `brightness`：星曜在地支的庙旺落陷状态；四化本身不写庙旺。
9. `dynamic-flow`：大限、流年、流月、流日、流时的动态标记和继承边界。
10. `relationship`：星曜、格局、宫位主题之间的关系结构。
11. `sample`：人工校盘样例和复核结论，只作校验，不直接升为理论。
12. `storage-boundary`：来源类型、可存储字段、阻断字段和复核队列。

每条主题映射必须保留 `sourceId`、`fragmentId`、`dedupKey`、`entityRefs`、`promotionStatus`。现代资料仍然只存元信息和项目自有摘要；公版古籍可以存原文、术语、篇目、版本和项目自有摘要。

## P35-E 入库边界

P35-E 规定入库门禁，资料不会因为被采集或清洗就自动进入解释层。

1. 公版古籍资料在来源、版本、篇目、实体引用完整时可以进入对应字典层。
2. 古籍目录、大学图书馆馆藏目录和现代书籍索引默认只进入元信息索引。
3. 网站、视频和现代资料自有摘要必须进入主题复核，复核通过后才可进入字典层。
4. 排盘软件差异只进入动态盘复核，不复制截图、版式、图标、商标或成套文案。
5. 现代书籍正文、表格原文、扫描图、受限馆藏影像和未脱敏个人资料直接拒绝入库。
6. 入库决策必须记录分数、门禁策略、目标层、复核队列、拒绝原因和审计轨迹。
9. 清洗流程固定为：来源登记 -> 可存储边界 -> 实体抽取 -> 去重 -> 冲突检测 -> 复核路由 -> 清洗结果。
10. 每类来源必须有输入/输出样例，覆盖 `metadata-only`、`needs-review`、`ready-for-dictionary` 和 `blocked` 的处理边界。
