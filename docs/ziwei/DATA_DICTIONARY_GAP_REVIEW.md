# 紫微斗数据字典缺口复核清单

更新日期：2026-07-05

## 文档目的

这份文档只处理紫微斗数数据字典的收口问题。

当前紫微斗数模块已经能排盘、展示十二宫、展示星曜、展示动态盘、显示命中的格局，并且已经建立星曜、宫位、地支、天干、五行局、四化、组合、格局和当前盘证据链。

但是，要用紫微斗数完整分析一个人，数据字典还不能只停留在“有条目、有一句解释、有基础规则”。后续必须继续补三类内容：

1. 星曜本体、入宫、组合、三方四正、动态盘之间的细节解释。
2. 当前盘命中以后，如何根据这张盘的证据生成综合解释。
3. 来源、冲突、复核和人工校盘样例，保证解释不是自由发挥。

本清单不新增行为映射，不做人格化分析，不继续拆采集后台。它只规定下一批紫微斗数数据字典应该补什么、补到什么程度才算闭合。

## 缺口一：杂曜细节分组与组合权重补强

当前已经有杂曜本体和入宫解释，但还不够细。杂曜不是每颗都能直接改写命盘主题，它们多数用于补充细节、提示事件倾向、说明环境条件或修饰主星表现。

下一批要按主题整理：

| 主题 | 需要补的内容 |
|---|---|
| 贵人助力 | 哪些杂曜表示助力、提携、文书便利、长辈帮助、制度资源 |
| 桃花人缘 | 哪些杂曜表示吸引力、交际、审美、情感牵动、关系复杂 |
| 孤寡隔阂 | 哪些杂曜表示疏离、迟滞、独立、情绪闭合、关系距离 |
| 刑忌压力 | 哪些杂曜表示口舌、官非、伤损、反复、延误、心理负担 |
| 仪饰声名 | 哪些杂曜表示名声、形象、礼仪、外在包装、场面资源 |
| 耗损迁动 | 哪些杂曜表示消耗、奔波、变化、破耗、迁移和环境不稳 |

验收标准：

1. 每颗杂曜必须有本体、入宫、同宫、对宫、三方四正、动态盘和误读边界。
2. 杂曜解释不能压过主星和主宫主题，除非同时有四化、煞曜、格局或三方四正支持。
3. 杂曜不强行套庙旺落陷。只按主题、位置、组合和盘层解释。

## 缺口二：年月日时流系星曜层级边界补强

流系星曜必须分层。年系星曜看年度主题，月系星曜看短期焦点，日系和时系更偏触发与提醒，不能把短周期星曜写成本命长期结构。

下一批要补：

| 盘层 | 解释边界 |
|---|---|
| 大限 | 十年阶段，解释人生阶段和长期环境 |
| 流年 | 年度主题，必须保留大限背景 |
| 流月 | 月度焦点，不能越过流年独立断长期趋势 |
| 流日 | 日度触发，只看短期事件提醒 |
| 流时 | 时段微调，只看临场变化和短促提示 |

验收标准：

1. 动态解释必须标明盘层。
2. 选择流年时保留大限背景。
3. 选择流月、流日、流时时必须说明上层来源。
4. 周期星不得替代本命主星。

## 缺口三：当前盘格局命中综合解释补强

格局总字典解释“这个格局是什么”。当前盘解释要回答“这张盘为什么命中、成色如何、哪里破、哪里能修复”。

下一批要补：

1. 当前盘格局命中证据。
2. 成格条件在盘中是否满足。
3. 破格条件是否出现。
4. 加吉、加煞、四化、庙旺落陷怎样影响成色。
5. 原盘、大限、流年、流月、流日、流时分别是哪一层命中。
6. 多个格局同时出现时，主格、辅格、冲突格、破格信号的排序。

验收标准：

1. 页面只显示盘中命中格局。
2. 每个命中格局必须带盘中证据。
3. 未命中格局只留在总字典，不进入当前盘结果。

## 缺口四：十二宫专题段落证据合成补强

十二宫不能只写“夫妻宫管感情”“官禄宫管事业”。每个宫位都要能转成读盘问题。

例如夫妻宫要看：

1. 本宫星曜说明关系对象和互动方式。
2. 对宫官禄说明关系与事业责任之间的牵动。
3. 三方四正说明财务、迁移、福德等支援或压力。
4. 四化说明关系中的引动点。
5. 煞曜和杂曜说明冲突、距离、消耗或细节。
6. 动态盘说明当前阶段关系主题是否被触发。

验收标准：

1. 每宫解释必须有本宫、对宫、三方四正、同宫星曜、四化和动态盘。
2. 段落必须能追溯来源字段，不能只堆标签。
3. 不做人格化分析，不写现代心理标签。

## 缺口五：四化来源天干与盘层差异复核

四化必须写清“谁的四化”。同一化象在本命、大限、流年、流月、流日、流时中的意义不同。

下一批要补：

| 项目 | 必填内容 |
|---|---|
| 来源天干 | 来自本命干、大限干、流年干、流月干、流日干还是流时干 |
| 目标星 | 化禄、化权、化科、化忌作用在哪颗星 |
| 目标宫 | 目标星落在哪个宫 |
| 盘层 | 当前解释属于原盘、大限、流年、流月、流日还是流时 |
| 关系宫位 | 是否牵动对宫、三方四正、夹宫和会照 |

验收标准：

1. 四化不显示庙旺落陷。
2. 四化不作为独立星曜亮度。
3. 四化只修正目标星、目标宫和当前盘层。

## 缺口六：地支空间组三合冲合刑害补强

地支层服务盘面空间，不做生肖性格解释。后续要把三合、六合、六冲、刑害、墓库、马地和败地写成盘面关系。

验收标准：

1. 每个地支必须说明宫位空间语境。
2. 四马地、四败地、四墓库地必须能被当前盘引用。
3. 三合、六合、六冲、刑害必须说明是增强、牵动、冲突、滞碍还是复核信号。

## 缺口七：古籍与现代资料来源人工复核

来源层已经建立，但资料深度还要继续补。

允许保存：

1. 公版古籍的书名、版本、卷册、篇目、术语位置和项目自有整理。
2. 现代网站的标题、网址、栏目、主题标签、实体标签、访问日期和项目自有摘要。
3. 用户自有输入和脱敏校盘样例。

暂不保存：

1. 现代书籍正文。
2. 现代网站正文大段复制。
3. 无法确认来源、无法复核、无法归类的断语。

验收标准：

1. 正式解释必须带来源线索或项目自有整理依据。
2. 有冲突的资料先进入复核队列。
3. 不把现代网站简略说法直接当最终理论。

## 缺口八：人工校盘样例复核与脱敏样例

后续需要脱敏样例来反查解释质量。样例不是用来改算法，而是用来发现解释是否太空、太泛、证据不足或互相冲突。

验收标准：

1. 样例不得含可识别个人信息。
2. 样例必须记录排盘参数、排盘版本、命中证据、人工判断和复核结论。
3. 样例只能校验解释层，不能覆盖固定排盘算法。

## 缺口九：星曜入宫文本深度抽样复核

入宫解释是读盘的核心。下一批先抽样六宫：命宫、夫妻、财帛、官禄、迁移、疾厄。

每条入宫资料要补：

1. 本宫含义。
2. 对宫影响。
3. 三方四正支援或压力。
4. 同宫主星、辅曜、煞曜、杂曜怎样改写语气。
5. 四化怎样引动。
6. 庙旺落陷怎样改变成色。
7. 大限、流年、流月、流日、流时怎样分层解释。

验收标准：

1. 入宫解释不能只有一句概括。
2. 盘中位置只显示当前盘实际出现位置。
3. 未出现位置留在总字典，不进入当前盘解释。

## 缺口十：动态盘继承解释段落补强

动态盘解释必须有继承链：

原盘是底盘，大限是十年阶段，流年是年度主题，流月是月度焦点，流日是日度触发，流时是时段微调。

验收标准：

1. 点击大限，显示大限命宫、大限十二宫和大限格局。
2. 点击流年，保留大限背景，叠加流年命宫、流年十二宫和流年格局。
3. 点击流月、流日、流时，继续保留上层背景。
4. 再次点击同一个大限时，清空流年、流月、流日、流时，回到原盘状态。
5. 动态盘解释不能改写原盘固定结构。
