# 紫微斗数字典字段模型

更新时间：2026-08-03 09:23:45 +08:00

状态：active-field-contract

Codex等外部执行智能体不得超出当前用户任务范围；本地程序在生效业务、安全和机器合同内自主运行，不从聊天或本句推导逐步Owner审批。


## 字段总原则

字段只定义一次，其他模块引用。星曜、宫位、地支、天干、五行局、四化、亮度、格局、动态盘层都不能在解释文件中重新造一套枚举。

数据字典字段分为三类：

| 类型 | 用途 |
|---|---|
| 基础字段 | 识别资料是什么，来自哪里，能不能用 |
| 解释字段 | 保存星曜、宫位、组合、格局的通用解释 |
| 调用字段 | 当前盘分析时记录命中证据、盘层和输出边界 |

## 通用基础字段

所有字典资料都要有这些字段。

| 字段 | 含义 |
|---|---|
| 资料编号 | 全局唯一，不参与显示结论 |
| 资料层 | 星曜本体、入宫、组合、格局、动态盘等 |
| 显示名称 | 中文名称 |
| 关联实体 | 星曜、宫位、地支、天干、格局或盘层引用 |
| 来源引用 | 资料来源编号、角色、可信度、复核状态 |
| 资料状态 | 可用、待复核、仅索引、禁止 |
| 适用盘层 | 原盘、大限、流年、流月、流日、流时 |
| 适用关系 | 同宫、对宫、三方四正、夹宫、会照 |
| 误读边界 | 哪些情况下不能直接使用 |
| 入库时间 | 资料进入项目的时间 |
| 复核记录 | 人工复核、冲突标记、修订原因 |

## 星曜本体字段

星曜本体用于解释“这颗星是什么”。

| 字段 | 必填 | 说明 |
|---|---|---|
| 星曜引用 | 是 | 引用星曜目录，不重复定义 |
| 星曜分类 | 是 | 主星、辅曜、煞曜、杂曜、周期流系等 |
| 所属系统 | 是 | 紫微系、天府系、辅佐系、煞曜系、杂曜系、年系、月系、日时系 |
| 五行阴阳 | 否 | 有明确来源才填 |
| 别名术语 | 否 | 古籍术语、民间别称、常见写法 |
| 核心象义 | 是 | 星曜最核心的象、气、事、功能 |
| 主要主题 | 是 | 可检索的主题标签 |
| 正向表现 | 是 | 条件良好时如何发挥 |
| 风险表现 | 是 | 条件失衡时如何表现 |
| 喜见条件 | 是 | 喜见哪些星、宫、四化、状态 |
| 忌见条件 | 是 | 忌见哪些煞忌、落陷、空劫或冲突结构 |
| 亮度用法 | 否 | 有亮度表时说明庙旺落陷如何修正 |
| 四化用法 | 否 | 该星被四化触发时如何看 |
| 动态用法 | 是 | 原盘、大限、流年、流月等层级差别 |
| 读盘顺序 | 是 | 本星进入分析时的固定顺序 |
| 误读边界 | 是 | 不能单星断、不能脱离宫位、不能脱离三方 |

## 宫位本体字段

宫位本体用于解释“这个宫管什么”。

| 字段 | 必填 | 说明 |
|---|---|---|
| 宫位引用 | 是 | 引用十二宫目录 |
| 宫位主题 | 是 | 该宫的核心议题 |
| 观察问题 | 是 | 分析该宫时要问的问题 |
| 人事物范围 | 是 | 该宫涉及的人、事、物 |
| 对宫关系 | 是 | 对宫如何影响该宫 |
| 三方关系 | 是 | 三方四正如何支援或施压 |
| 宫线关系 | 是 | 命迁、财官、夫妻福德等 |
| 动态用法 | 是 | 大限、流年、流月触发时如何读 |
| 空宫规则 | 是 | 无主星时如何借对宫并复核三方 |
| 误读边界 | 是 | 不可把单宫无限扩大 |

## 星曜入宫字段

星曜入宫用于解释“某星落某宫”。

| 字段 | 必填 | 说明 |
|---|---|---|
| 星曜引用 | 是 | 引用星曜目录 |
| 宫位引用 | 是 | 引用十二宫目录 |
| 落宫转换 | 是 | 星曜本体如何变成该宫主题 |
| 宫位重点 | 是 | 当前宫位最该观察什么 |
| 正向条件 | 是 | 何时该宫主题较顺 |
| 风险条件 | 是 | 何时该宫主题较费力 |
| 同宫看法 | 是 | 同宫星曜如何改变解释 |
| 对宫看法 | 是 | 对宫星曜如何改变解释 |
| 三方四正看法 | 是 | 三方四正如何加权或降权 |
| 四化看法 | 是 | 四化来源和目标星如何触发该宫 |
| 庙旺落陷看法 | 否 | 有亮度表时如何修正 |
| 动态看法 | 是 | 原盘、大限、流年、流月等如何分层 |
| 当前盘证据字段 | 是 | 生成当前盘解释时需要哪些证据 |

## 星曜组合字段

星曜组合用于解释“两个或多个星如何互相改变含义”。

| 字段 | 必填 | 说明 |
|---|---|---|
| 组合星曜 | 是 | 两颗或多颗星曜引用 |
| 主辅关系 | 是 | 谁是主轴，谁是修饰、推动、破坏或修复 |
| 关系类型 | 是 | 同宫、对宫、三方、夹宫、会照 |
| 组合主旨 | 是 | 组合后的核心含义 |
| 增强条件 | 是 | 哪些条件让组合成色提高 |
| 破坏条件 | 是 | 哪些条件让组合失衡或破格 |
| 宫位差异 | 是 | 入不同宫位时如何转换 |
| 动态差异 | 是 | 原盘、大限、流年等层级的差别 |
| 误读边界 | 是 | 不能把星曜解释简单相加 |

## 关系结构字段

关系结构用于解释“盘面关系怎么读”。

| 字段 | 必填 | 说明 |
|---|---|---|
| 结构名称 | 是 | 同宫、对宫、三方四正、夹宫、会照等 |
| 结构定义 | 是 | 关系如何成立 |
| 读取顺序 | 是 | 先看什么，后看什么 |
| 加权规则 | 是 | 哪些关系权重大，哪些只作参考 |
| 冲突规则 | 是 | 关系相互矛盾时怎么处理 |
| 动态规则 | 是 | 流层叠加时谁继承谁 |
| 输出边界 | 是 | 不能输出哪些过度结论 |

## 状态修正字段

状态修正用于解释“星曜和宫位如何被加权或降权”。

| 状态 | 必备字段 |
|---|---|
| 庙旺落陷 | 星曜、地支、状态、承接力、风险修正、来源 |
| 四化 | 来源天干、四化名称、目标星、目标宫、盘层、触发方向 |
| 吉曜 | 支援类型、适用关系、增强主题、限制条件 |
| 煞曜 | 压力类型、适用关系、风险主题、修复路径 |
| 空劫 | 落空类型、断裂主题、虚耗边界、复核条件 |
| 禄马 | 资源来源、移动方式、适用宫位、动态触发 |
| 桃花 | 吸引、关系、人际、审美、欲望边界 |
| 周期星 | 所属周期、有效层级、持续时间、不得反推原盘 |

## 格局字段

格局字典和当前盘格局必须分开。

| 字段 | 格局字典 | 当前盘命中 |
|---|---|---|
| 格局名称 | 必填 | 必填 |
| 格局分类 | 必填 | 必填 |
| 核心星曜 | 必填 | 必填并标注盘中位置 |
| 成格条件 | 必填 | 必须由算法命中 |
| 破格条件 | 必填 | 必须复核当前盘是否出现 |
| 加吉条件 | 必填 | 当前盘有才显示 |
| 加煞条件 | 必填 | 当前盘有才显示 |
| 格局本体解释 | 必填 | 作为背景 |
| 当前盘解释 | 不填 | 必填，结合盘面证据 |
| 动态盘用法 | 必填 | 按当前选择的盘层显示 |
| 隐藏规则 | 必填 | 未命中不展示 |

## 动态盘字段

动态盘字段必须保留层级。

| 字段 | 说明 |
|---|---|
| 盘层 | 原盘、大限、流年、流月、流日、流时 |
| 命宫位置 | 当前层级的命宫在哪里 |
| 十二宫映射 | 当前层级十二宫如何转动 |
| 继承来源 | 继承原盘、大限、流年中的哪一层 |
| 显示标签 | 原命、大限命、流年命、流月命、流日命、流时命 |
| 四化来源 | 本命干、大限干、流年干、流月干、流日干、流时干 |
| 输出权重 | 长期、中期、年度、月度、日度、时段 |
| 取消规则 | 再次点击同一层级时回到上一级或原盘状态 |

## 当前盘输出字段

当前盘分析输出必须带证据。

| 字段 | 说明 |
|---|---|
| 分析主题 | 命身、事业、财务、感情、家庭、健康、迁移、风险等 |
| 当前结论 | 根据当前盘证据生成的中文解释 |
| 证据星曜 | 实际出现在盘中的星曜 |
| 证据宫位 | 实际落宫 |
| 同宫证据 | 同宫星曜和状态 |
| 对宫证据 | 对宫星曜和状态 |
| 三方证据 | 三方四正星曜和状态 |
| 四化证据 | 来源天干、目标星、目标宫 |
| 亮度证据 | 庙旺落陷或不论 |
| 格局证据 | 命中格局、破格、加吉、加煞 |
| 动态证据 | 原盘、大限、流年、流月、流日、流时 |
| 增强信号 | 哪些条件支持结论 |
| 削弱信号 | 哪些条件削弱结论 |
| 复核提示 | 哪些资料仍需人工校验 |
