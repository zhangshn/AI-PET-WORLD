## 模块定位

本文件对应 P36-H-5，用来把“星曜数据字典到底够不够用”拆成可复核的样本。
当前不继续扩展采集后台，也不做人格化映射；只检查紫微斗数正统读盘所需要的资料层是否能支撑解释。

抽样先选六颗主星：紫微、贪狼、巨门、廉贞、武曲、破军。
这六颗分别覆盖中枢统御、欲望资源、口舌辨析、规则边界、财务执行、破旧立新，能代表目前字典最容易被误读、误简化或过度断语的几类星曜。

| 对宫与三方四正 | 解释对宫牵引、三方支援、四正压力、夹宫与会照 | 需要继续细化 |
| 四化触发 | 解释谁的四化、来源天干、目标星、目标宫、盘层继承 | 需要继续细化 |

## 使用规则

1. 总字典解释星曜本身，不直接等于当前盘结论。
2. 当前盘只显示盘中真实命中的星曜、宫位、组合、格局、四化和动态盘证据。
3. 星曜解释必须先读本体，再读入宫，再读同宫、对宫、三方四正、夹宫会照。
4. 四化必须写清来源天干、来源盘层、目标星、目标宫，不能给四化本身标庙旺落陷。
5. 大限、流年、流月、流日、流时要逐层降权，短周期不能反推成本命结论。
6. 现代网站只作为解释结构和栏目参考，不复制正文，不把单站内容直接升为硬规则。
7. 资料不足时进入复核队列，不用空泛断语补齐。
