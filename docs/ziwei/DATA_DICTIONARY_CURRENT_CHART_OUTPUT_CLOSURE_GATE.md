## 模块定位

本文件对应 P36-H-10，用来把“哪些资料可以进入当前盘输出”固定成最终门禁。

前面已经补了星曜、宫位、组合、格局、四化、动态盘、段落样例和真实盘例回归。P36-H-10 不再继续散补资料，而是把输出边界锁住：

1. 允许进入当前盘：必须有当前盘命中证据。
2. 只留总字典：通用解释、完整理论、未命中的格局和组合。
3. 隐藏：未命中、盘层未选中、证据字段不足、来源边界不清。
4. 复核：来源冲突、证据不完整、高风险主题、层级混乱。
5. 禁止：复制现代正文、人格化映射、医学诊断、收益承诺、恐吓式断语。

## 八类输出门禁

| 门禁 | 输出状态 | 作用 |
|---|---|---|
| 本命宫位主轴输出门禁 | 允许进入当前盘 | 命宫、身宫和十二宫本宫段落必须具备本宫、对宫、三方四正和四化证据 |
| 星曜本体输出门禁 | 默认只留总字典 | 星曜本体解释只有落到当前盘宫位并有证据时才进入当前盘 |
| 星曜组合输出门禁 | 允许进入当前盘 | 同宫、对宫、三方四正、夹宫会照必须写清关系类型 |
| 四化来源输出门禁 | 允许进入当前盘 | 必须写清谁的四化、来源盘层、目标星和目标宫，禁止给四化本身标庙旺落陷 |
| 格局命中输出门禁 | 允许进入当前盘 | 必须有 patternId、conditionText、matchedPalaces 和 sourceRuleIds |
| 动态盘层级输出门禁 | 允许进入当前盘 | 大限、流年、流月、流日、流时必须逐层继承和降权 |
| 高风险主题输出门禁 | 必须复核 | 疾厄、财务、关系、法律和风险主题只做证据复核，不做现实替代判断 |
| 来源与版权输出门禁 | 禁止外部正文进入当前盘 | 现代网站和现代书籍正文不得进入当前盘，只能保留元信息和自有摘要 |

## 当前盘最终准入条件

当前盘输出必须同时满足：

1. 有当前盘命中证据。
2. 有 dictionaryRefs。
3. 有 sourceRuleIds。
4. 有 evidenceLines。
5. 有 interpretationBoundary。
6. 能写清盘层、本宫、对宫、三方四正。
7. 能写清四化来源、目标星和目标宫。
8. 动态盘能写清原盘、大限、流年、流月、流日、流时层级。
9. 未命中内容必须隐藏。
10. 高风险主题必须降权和复核。

## 禁止输出清单

当前盘禁止输出：

1. 未命中的格局、组合、四化和动态盘标签。
2. 总字典全文。
3. 现代网站正文。
4. 现代书籍正文。
5. 人格化映射。
6. 医学诊断。
7. 投资收益承诺。
8. 替用户做关系、法律、财务决定的文字。
9. 用流年、流月、流日、流时反推本命长期结论。
10. 恐吓式、保证式、宿命化断语。

## 验收结论

本合同把当前盘解释的最终门禁固定下来。

后续继续扩充资料时，资料可以先进入总字典；但要进入当前盘输出，必须通过本文件的八类门禁。没有命中证据、来源边界不清、动态层级不明或高风险越界的内容，都只能隐藏或进入复核。
