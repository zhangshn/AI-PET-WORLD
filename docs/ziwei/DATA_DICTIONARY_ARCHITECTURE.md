# 紫微斗数数据字典总架构

更新时间：2026-08-03 09:23:45 +08:00

状态：active-subsystem-architecture

不允许自由发挥；除非发现错误导致无法继续，必须先停下来询问项目所有者。


## 目标

数据字典的目标不是替代排盘，也不是直接生成某个人的结论，而是建立一套可复用、可追溯、可继续扩充的紫微斗数资料底座。

后续分析一个盘时，必须先从数据字典取资料，再结合当前盘的实际星曜、宫位、三方四正、四化、庙旺落陷、格局和动态盘层级，生成当前盘解释。

## 资料参考边界

`ziwei.my` 这类网站只作为栏目结构、主题覆盖和资料缺口的参考，不复制正文、不复制页面排版、不把它的句子直接写入项目。可记录的内容只有页面地址、页面标题、栏目、涉及星曜、涉及宫位、涉及格局、主题标签和项目自有摘要。

古籍、公版资料、项目自有整理和人工校盘资料可以进入字典；现代书籍正文、现代网站正文、截图、软件版式、未脱敏案例不进入解释正文。

## 总目录

```txt
紫微斗数数据字典
  01 来源资料层
  02 基础实体层
  03 星曜本体层
  04 宫位本体层
  05 星曜入宫层
  06 星曜组合层
  07 关系结构层
  08 状态修正层
  09 格局层
  10 动态盘层
  11 专题分析层
  12 当前盘调用层
```

每一层只做自己的事情。星曜本体不写某一张盘的结论；星曜入宫不重复定义星曜；格局层不重新排盘；当前盘调用层只读取已命中的资料，不展示未命中的格局。

## 01 来源资料层

来源资料层记录资料从哪里来、能不能存、能用于什么层、是否需要复核。

| 字段组 | 内容 |
|---|---|
| 来源身份 | 来源名称、来源类型、版本、作者或编者、页面地址或馆藏位置 |
| 存储边界 | 可存原文、仅元信息、仅自有摘要、用户自有输入、禁止入库 |
| 适用范围 | 星曜本体、入宫、组合、格局、四化、动态盘、样例校准 |
| 复核状态 | 未复核、已复核、争议、仅索引、禁止使用 |

来源层只决定资料资格，不直接决定命盘结论。

## 02 基础实体层

基础实体层只定义一次，其他层全部引用。

| 实体 | 唯一来源 | 用途 |
|---|---|---|
| 星曜 | 星曜目录 | 主星、辅曜、煞曜、杂曜、年系、月系、日时系 |
| 十二宫 | 宫位目录 | 命、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母 |
| 十二地支 | 地支目录 | 宫位空间、四马地、四败地、四墓库地、三合局 |
| 十天干 | 天干目录 | 阴阳五行、四化来源、流层触发 |
| 五行局 | 五行局目录 | 起运、局数、基础盘信息 |
| 四化 | 四化规则表 | 化禄、化权、化科、化忌的目标星和来源天干 |
| 庙旺落陷 | 亮度表 | 只作用于有亮度定义的星曜，不给四化硬套亮度 |

这一层的原则是：不在解释资料里重复定义枚举，不在页面组件里临时造规则。

## 03 星曜本体层

星曜本体解释一颗星本身是什么，不讨论它在某个盘中一定发生什么。

每颗星曜至少要有：

| 模块 | 说明 |
|---|---|
| 星曜身份 | 分类、别名、五行、阴阳、所属系统 |
| 核心象义 | 这颗星主要代表的气质、功能、象、事 |
| 正向条件 | 何时容易表现为助力、资源、秩序、名位、执行或修复 |
| 风险条件 | 何时容易表现为阻滞、反复、破耗、争执、失衡或虚浮 |
| 庙旺落陷 | 有亮度定义时说明发挥顺逆；无定义时标记不论或待复核 |
| 四化关系 | 该星被化禄、化权、化科、化忌触发时的基础读法 |
| 动态层级 | 原盘、大限、流年、流月、流日、流时的使用边界 |
| 误读边界 | 不能只凭单星断事，不能脱离宫位和三方四正 |

星曜本体是后续所有组合解释的根，不直接替代当前盘分析。

## 04 宫位本体层

宫位本体解释十二宫各自管什么主题。

| 宫位资料 | 说明 |
|---|---|
| 基本主题 | 该宫负责的人、事、物、关系、处境 |
| 宫位问题 | 分析该宫时应该问哪些问题 |
| 相关宫线 | 命迁线、财官线、夫妻福德线、父母疾厄线等 |
| 动态用法 | 大限、流年、流月等进入该宫时如何变成阶段主题 |
| 取象边界 | 不能把一个宫位的主题无限扩大 |

宫位解释必须和星曜解释分开。星曜说明“什么力量”，宫位说明“落到哪个生活领域”。

## 05 星曜入宫层

星曜入宫层是星曜本体进入十二宫后的转换解释。

例如贪狼本体讲欲望、社交、才艺、变化；贪狼入夫妻宫时要转成亲密关系、吸引、互动边界、情感变化和关系资源；贪狼入财帛宫时要转成收入方式、消费欲望、资源流动和机会风险。

每条入宫解释都要包含：

| 模块 | 说明 |
|---|---|
| 落宫含义 | 星曜本体如何转换到该宫主题 |
| 宫位重点 | 该宫最该观察的主题 |
| 喜见条件 | 适合哪些吉曜、亮度、四化、三方支援 |
| 忌见条件 | 哪些煞忌、空劫、落陷或组合会让该宫主题变差 |
| 对宫参考 | 对宫如何影响该星曜在本宫的表现 |
| 三方四正 | 三方会入哪些星曜时要加权或降权 |
| 动态提示 | 大限、流年、流月等盘层触发时如何读 |

这是目前最需要大规模补深的层。

## 06 星曜组合层

组合层解释星曜之间如何互相改变含义，不是把两颗星的解释相加。

| 组合类型 | 解释重点 |
|---|---|
| 同宫 | 两星直接混合，影响最明显 |
| 对宫 | 形成拉扯、照见、对象关系和外部反馈 |
| 三方四正 | 形成结构支援、结构压力、格局成色 |
| 夹宫 | 两侧环境塑形，常影响被夹宫位的承接 |
| 会照 | 远距离互相参与，要看强弱和盘层 |
| 四化牵动 | 天干触发某颗星，连接资源、权责、名誉和牵挂 |
| 辅煞杂叠加 | 辅曜加分、煞曜加压、杂曜补细节，不能同权处理 |

组合解释要写清楚谁主、谁辅、谁触发、谁破坏、谁修复。

## 07 关系结构层

关系结构层不是解释某颗星，而是解释读盘关系。

| 结构 | 用途 |
|---|---|
| 三方四正 | 判断一个宫位的结构支援和结构压力 |
| 对宫 | 判断对照关系、外部对象和互补冲突 |
| 夹宫 | 判断左右环境如何塑造中间宫位 |
| 空宫借对宫 | 无主星宫位如何借对宫主星，并复核三方 |
| 命迁线 | 自我与外部环境的互动 |
| 财官线 | 资源、事业、行动结果的互证 |
| 夫妻福德线 | 关系互动与内在满足的互证 |
| 父母疾厄线 | 出身、支援、身体状态和压力来源 |

关系结构层是当前盘综合分析的骨架。

## 08 状态修正层

状态修正层给星曜和宫位加权或降权。

| 状态 | 读法 |
|---|---|
| 庙旺落陷 | 看星曜发挥顺逆和承接力，不单独决定吉凶 |
| 四化 | 看来源天干、目标星、目标宫、盘层，不套庙旺 |
| 六吉 | 看支援、修饰、贵助、文名、制度资源 |
| 六煞 | 看压力、阻滞、冲突、破耗、突发成本 |
| 空劫 | 看落空、虚耗、断裂、非稳定结构 |
| 禄马 | 看资源与移动，必须结合宫位和盘层 |
| 桃花 | 看吸引、人际、欲望、审美和关系边界 |
| 孤寡刑忌 | 看孤立、约束、纠结、压力和修复成本 |
| 博士岁前将前长生 | 看年度、阶段、气势和周期细节 |

状态修正层不能越权替代星曜本体和落宫解释。

## 09 格局层

总格局字典解释每个格局本身，当前盘格局只展示盘中命中的格局。

每个格局要分两套解释：

| 解释 | 作用 |
|---|---|
| 格局本体解释 | 说明这个格局是什么、核心星曜是什么、为什么成立、传统含义是什么 |
| 当前盘命中解释 | 只针对当前盘命中的格局，结合命宫、身宫、宫位、三方、四化、庙旺、破格和动态盘层级 |

格局资料必须包含成格条件、破格条件、加吉条件、加煞条件、强弱层次、动态盘用法和误读边界。

## 10 动态盘层

动态盘层分原盘、大限、流年、流月、流日、流时。

| 盘层 | 作用 |
|---|---|
| 原盘 | 长期底盘、基础结构、命身和十二宫根基 |
| 大限 | 十年阶段主题，不能覆盖原盘，只能阶段放大 |
| 流年 | 年度主题，必须继承原盘和大限 |
| 流月 | 月度重点，必须服从流年主线 |
| 流日 | 日度触发，只看短期事件和提醒 |
| 流时 | 时段微调，只看临场状态 |

点击大限时显示大限命宫和大限十二宫；点击流年时保留大限标记，并叠加流年命宫和流年十二宫；流月、流日、流时以此类推。

## 11 专题分析层

专题分析层把资料组织成可读主题，但仍然不人格化。

| 专题 | 需要读取的资料 |
|---|---|
| 命身结构 | 命宫、身宫、命迁线、主星、三方四正 |
| 事业 | 官禄、财帛、迁移、命宫、四化、格局 |
| 财务 | 财帛、田宅、福德、官禄、禄马、煞忌 |
| 感情 | 夫妻、福德、命宫、迁移、桃花、煞忌 |
| 家庭 | 父母、兄弟、子女、田宅、相关四化 |
| 健康 | 疾厄、父母、命宫、煞忌、动态触发 |
| 迁移 | 迁移、命宫、天马、四马地、动态盘 |
| 风险 | 煞曜、化忌、空劫、破格、不良格局 |

专题层输出的是紫微斗数分析，不是现代心理标签。

## 12 当前盘调用层

当前盘调用层只做一件事：读取当前盘已经命中的资料，组合成可复核解释。

每条当前盘解释都必须能回答：

1. 结论说的是什么。
2. 证据来自哪颗星。
3. 星曜落在哪个宫。
4. 同宫有什么。
5. 对宫有什么。
6. 三方四正有什么。
7. 是否有四化。
8. 是否有庙旺落陷。
9. 是否命中格局或破格。
10. 属于原盘、大限、流年、流月、流日还是流时。
11. 哪些证据增强。
12. 哪些证据削弱。
13. 哪些内容需要复核。

没有证据链的解释不能进入当前盘报告。
