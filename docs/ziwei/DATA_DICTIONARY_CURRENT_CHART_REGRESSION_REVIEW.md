## 模块定位

本文件定义 P36-H-9，使用黄金样本复核当前盘解释资料是否稳定。

P36-H-9 要求 P36-H-8 定义的段落组织规则能够在固定盘例上反复复现。同一套出生资料和动态时间，每次都必须得到相同的命宫、身宫、五行局、顺逆方向、起运年龄、大限宫、流年宫、流月宫、流日宫和流时宫。
