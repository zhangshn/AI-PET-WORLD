# 紫微斗数数据字典 P36-H-9 真实盘例回归复核

更新时间：2026-07-06

## 模块定位

本文件对应 P36-H-9，用已有黄金样本复核当前盘解释资料是否稳定。

P36-H-8 已经证明资料可以组织成段落，P36-H-9 进一步要求这些段落必须能落到固定盘例上反复复现。也就是说，同一套出生资料和动态时间，每次都必须得到相同的命宫、身宫、五行局、顺逆方向、起运年龄、大限宫、流年宫、流月宫、流日宫和流时宫。

这一步仍然只做正统紫微斗数证据分析，不做人格化映射，不复制现代网站正文。

## 每个样本必须复核

| 复核项 | 说明 |
|---|---|
| 出生资料 | 年、月、日、时、分、性别和历法必须和黄金样本一致 |
| 动态时间 | 当前年龄、流年、农历月日、流时必须固定 |
| 核心预期 | 命宫、身宫、五行局、总星曜数量、顺逆方向、起运年龄、是否起运 |
| 动态宫位 | 原盘、大限、流年、流月、流日、流时命宫 |
| 当前盘证据链 | 必须生成本命宫位、星曜、同宫组合、宫位关系、动态盘和格局边界证据 |
| 段落目标 | 当前盘段落必须说明本样本最关键的读盘边界 |
| 隐藏规则 | 未命中的格局、未启用的盘层、待复核资料不得显示为结论 |
| 来源边界 | 现代资料只保留结构和元信息，不复制正文 |
