# 紫微斗数数据字典 P36-H-8 当前盘解释段落样例抽查

更新时间：2026-08-03 09:23:45 +08:00

## 模块定位

本文件对应 P36-H-8，用来检查数据字典里的资料能不能真正合成“当前盘解释段落”。

这一步不是继续堆单颗星曜资料，也不是做页面排版，而是抽查读盘输出是否能按正统紫微斗数顺序讲清楚：

1. 先定盘层和宫位。
2. 再看本宫主星、辅曜、煞曜、杂曜。
3. 再看对宫、三方四正和夹宫会照。
4. 再看四化来源、庙旺落陷、成格破格和修复条件。
5. 再看大限、流年、流月、流日、流时的动态盘继承和降权。
6. 最后只输出当前盘真实命中的证据，不复制总字典全文，不做人格化映射。

## 六个样例场景

| 样例 | 盘层 | 宫位 | 抽查重点 |
|---|---|---|---|
| 原盘命宫主轴段落样例 | 原盘 | 命宫 | 主星、同宫、三方四正、格局主轴和四化边界 |
| 原盘夫妻宫关系段落样例 | 原盘 | 夫妻宫 | 关系结构、对宫牵引、桃花杂曜和煞忌边界 |
| 原盘财帛宫资源段落样例 | 原盘 | 财帛宫 | 资源来源、财官迁命承接、禄马权科和消耗边界 |
| 大限官禄宫阶段段落样例 | 大限 | 官禄宫 | 十年阶段、原盘继承、流年触发和阶段降权 |
| 流年迁移宫事件段落样例 | 流年 | 迁移宫 | 年度外部环境、移动变化、上层盘继承和事件窗口 |
| 流月疾厄宫短期复核段落样例 | 流月 | 疾厄宫 | 短期承压、作息节奏、修复资源和医学边界 |

## 每个样例必须包含

| 段落 | 作用 |
|---|---|
| 核心问题 | 说明这个宫位和盘层到底要回答什么 |
| 命中证据 | 列出本宫、星曜、三方四正、四化、格局、sourceRuleIds 和资料边界 |
| 段落顺序 | 固定当前盘输出的阅读顺序，避免从结论倒推证据 |
| 样例段落 | 用项目自有语言写一段可读的当前盘分析 |
| 解释规则 | 规定如何读本宫、对宫、三方四正、四化和动态层 |
| 隐藏规则 | 没有命中、没有证据、盘层未选中时不显示 |
| 降权规则 | 证据不足、短周期触发、煞忌重或来源冲突时降权 |
| 来源边界 | 现代资料只参考结构和标签，不复制正文 |
| 复核清单 | 检查是否讲清楚、是否越界、是否混淆总字典和当前盘 |
| 复核备注 | 标记真实盘例抽查方向 |

## 当前盘段落输出边界

当前盘段落只能回答“这张盘里已经出现什么证据，以及这些证据按紫微斗数规则如何组合”。它不能做以下事情：

1. 不能把总字典里所有格局都显示出来。
2. 不能把未命中的星曜组合写成命盘结论。
3. 不能把流年、流月、流日、流时反推成本命定论。
4. 不能复制现代网站或现代书籍正文。
5. 不能做人格化映射。
6. 不能在疾厄、风险、关系、财务等主题上做恐吓式或保证式断语。

## 验收结论

本合同已经固定当前盘解释段落样例抽查。现在数据字典不只是“有星曜解释”和“有格局解释”，还开始具备把资料合成当前盘段落的检查入口。
