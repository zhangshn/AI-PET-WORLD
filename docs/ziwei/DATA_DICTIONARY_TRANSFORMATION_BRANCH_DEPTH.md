## 定位

本文件只记录紫微斗数数据字典的固定理论补强，不做页面交互、不做行为映射、不做人格化分析。

本批补强解决两个问题：
1. 四化必须写清楚“是谁的四化”，不能只显示“化禄、化权、化科、化忌”。
2. 十二地支不能只解释单个地支，还要解释四马地、四败地、四墓库地、三合局、六冲、六合、刑害等盘面空间关系。

## 四化来源盘层

四化只说明禄、权、科、忌的触发和牵引，不给四化本身标庙旺落陷。庙旺落陷属于星曜状态，用来修正目标星承接力。

| 盘层 | 来源 | 解释边界 |
|---|---|---|
| 本命四化 | 出生年干 | 底盘长期牵引，说明一生结构中的资源、责任、名声和牵挂，不等于当前事件 |
| 大限四化 | 当前大限天干 | 十年阶段主题，必须叠在原盘上读，不改写原盘结构 |
| 流年四化 | 当前流年天干 | 年度触发，必须保留大限和原盘背景 |
| 流月四化 | 当前流月语境天干 | 月度焦点，服从流年主线 |
| 流日四化 | 当前流日语境天干 | 当天触发，只做日度提示 |
| 流时四化 | 当前流时语境天干 | 时段微调，只做临场提示，不放大成长期结论 |

输出当前盘解释时必须写清：
1. 来源盘层：本命、大限、流年、流月、流日或流时。
2. 来源天干：该四化由哪一层的天干触发。
3. 目标星：哪颗星被化禄、化权、化科或化忌标记。
4. 目标宫：该目标星落在哪个宫位，当前盘层下对应哪个宫名。
5. 继承关系：短周期必须继承上层盘。切到流年时不删除大限背景，切到流月时不删除流年和大限背景。
6. 关系结构：同宫、对宫、三方四正、夹宫、会照如何参与。
7. 格局关系：该四化是增强格局、破格复核、应期触发，还是只作为背景。
8. 隐藏规则：当前盘没有命中时不显示，未选择对应流层时不显示。

## 地支空间关系

地支空间服务盘面分析，不是生肖解释。

| 关系 | 地支 | 主要含义 | 误读边界 |
|---|---|---|---|
| 四马地 | 寅、申、巳、亥 | 启动、迁动、转换、外部牵引、资源流动 | 不等于必然远行 |
| 四败地 | 子、午、卯、酉 | 外显、关系、审美、名声、欲望、评价 | 不等于感情结论 |
| 四墓库地 | 辰、戌、丑、未 | 收藏、积累、旧账、责任、结构压力 | 不等于一定坏，也不单独断财富或疾病 |
| 水局 | 申、子、辰 | 信息、流动、资源循环、情绪暗流 | 单个地支不能称成局 |
| 木局 | 亥、卯、未 | 生发、成长、计划、学习、关系延伸 | 不等于必然吉 |
| 火局 | 寅、午、戌 | 行动、曝光、责任、热度、推动 | 热度高也可能带来消耗 |
| 金局 | 巳、酉、丑 | 规则、执行、收敛、技术、财务、判断 | 不等于必然有财 |
| 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 | 拉扯、对立、变动、外部反馈、结构打开 | 冲不是一定坏 |
| 六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 牵连、协商、暗合、缓冲、资源串联 | 合不等于一定好 |
| 刑害 | 依传统刑害关系复核 | 压力、暗伤、规训、误会、内耗、不顺畅 | 刑害不等于必然灾祸 |

## 使用顺序

当前盘解释不得直接从字典段落跳到结论，必须按以下顺序：
1. 先确认当前盘层：原盘、大限、流年、流月、流日、流时。
2. 再确认宫位：本宫、对宫、三方四正和夹宫。
3. 再确认星曜：主星、辅曜、煞曜、杂曜、周期流系星曜。
4. 再确认状态：庙旺落陷只给星曜，不给四化。
5. 再确认四化：谁的四化、来源天干、目标星、目标宫。
6. 再确认地支空间：四马、四败、四墓库、三合、六冲、六合、刑害。
7. 最后进入当前盘解释：只显示命中的内容，未命中资料留在总字典。
