# 紫微斗数数据字典大模块蓝图

更新时间：2026-08-03 09:23:45 +08:00

状态：active-data-blueprint

Codex等外部执行智能体不得超出当前用户任务范围；本地程序在生效业务、安全和机器合同内自主运行，不从聊天或本句推导逐步Owner审批。


## 模块目标

本模块用于重新收口紫微斗数数据字典。数据字典不是当前命盘解释，也不是页面展示文案，而是后续所有紫微斗数分析的资料底座。

后续分析一个人时，顺序必须固定为：

1. 先读取星曜、宫位、地支、天干、五行局、四化、庙旺落陷、格局、动态盘等基础资料。
2. 再读取当前命盘真实命中的星曜、宫位、组合、三方四正、夹宫、四化、格局和动态盘层级。
3. 最后生成当前命盘的正统紫微斗数分析。

数据字典只能回答“这个资料本身怎么理解”；当前命盘分析才回答“这张盘为什么这样判断”。

## 总体边界

| 层级 | 作用 | 禁止事项 |
|---|---|---|
| 总字典 | 保存通用理论、星曜解释、宫位解释、组合解释、格局解释 | 不直接断某个人，不显示未命中的格局为当前盘结论 |
| 当前盘命中层 | 只读取当前盘实际出现的星曜、宫位、组合、格局和动态标记 | 不把总字典所有内容都铺到当前盘 |
| 当前盘解释层 | 根据证据链合成整盘分析 | 不脱离星曜落宫、三方四正、四化来源和盘层 |
| 复核层 | 标记来源冲突、古籍差异、算法差异和人工校盘问题 | 不把未复核资料直接当成定论 |

## 星曜本体资料标准

每一颗星曜都必须先有“本体解释”，然后才允许进入入宫、组合和当前盘分析。

| 字段 | 要求 |
|---|---|
| 星曜身份 | 写明星曜分类、所属系统、是否主星、是否辅曜、是否煞曜、是否杂曜、是否周期流系星曜 |
| 基础象义 | 写明这颗星代表的气、象、人、事、物、关系、资源、压力或事件类型 |
| 正向表现 | 写明在何种条件下成为助力、秩序、资源、贵人、名位、行动力或修复力 |
| 风险表现 | 写明在何种条件下成为阻滞、破耗、纠缠、孤立、失衡、反复或虚耗 |
| 喜见条件 | 写明喜见哪些主星、辅星、四化、庙旺、宫位结构和三方支援 |
| 忌见条件 | 写明忌见哪些煞曜、化忌、空劫、落陷、破格、冲突结构 |
| 庙旺落陷 | 只有传统亮度表覆盖的星曜才写庙旺落陷；没有亮度来源的杂曜不硬套庙旺 |
| 四化关系 | 必须标明是生年四化、大限四化、流年四化、流月四化、流日四化还是流时四化 |
| 动态层级 | 写明原盘、大限、流年、流月、流日、流时分别能读到什么层级 |
| 误读边界 | 写明不能单星断事，不能脱离宫位，不能脱离三方四正，不能脱离四化来源 |

## 星曜入宫资料标准

星曜入宫不是重复星曜本体，而是把星曜含义转换到具体生活领域。

每条星曜入宫解释必须包含：

| 字段 | 要求 |
|---|---|
| 落宫转换 | 这颗星进入该宫后，本体象义如何转成该宫主题 |
| 本宫重点 | 该宫最该观察的问题是什么 |
| 同宫影响 | 同宫星曜如何增强、削弱、转向或制造矛盾 |
| 对宫影响 | 对宫如何形成外部对象、压力、补充或镜像 |
| 三方四正 | 三方四正如何决定结构支援、资源来源和实际成色 |
| 夹宫影响 | 左右邻宫是否形成夹辅、夹煞、夹忌、夹禄、夹权、夹科 |
| 四化触发 | 四化来自哪一层天干，目标星落在哪个宫，如何牵动本宫主题 |
| 庙旺修正 | 有亮度时说明承接强弱，没有亮度时只写作用强弱，不写庙旺 |
| 动态读法 | 原盘看长期底色，大限看阶段主题，流年看年度触发，流月以下看短周期应期 |
| 当前盘证据 | 当前盘使用时必须能回到星曜、宫位、盘层、关系和来源 |

## 十二地支与空间组

十二地支不是装饰字段，而是宫位空间语境。

| 空间组 | 地支 | 读法 |
|---|---|---|
| 四马地 | 寅、申、巳、亥 | 主动象、迁移象、转换象、奔波象、跨界象，适合看迁移、变化、外部机会和不稳定因素 |
| 四败地 | 子、午、卯、酉 | 主桃花、人际、显露、审美、欲望、关系牵引，也容易带来情绪、吸引、曝光和反复 |
| 四墓库地 | 辰、戌、丑、未 | 主收藏、积累、延迟、阻滞、库气、旧事、资源封存和需要开启的结构 |
| 三合局 | 申子辰、寅午戌、亥卯未、巳酉丑 | 用于判断三方结构的气势来源，不能只看单宫 |
| 对冲轴 | 子午、丑未、寅申、卯酉、辰戌、巳亥 | 用于判断对宫拉扯、外部对象和主题反复 |

地支解释必须服务于宫位和星曜，不得单独扩大成断语。

## 庙旺落陷与杂曜边界

庙旺落陷只用于有明确亮度资料的星曜。四化不是星曜亮度，不写庙旺。杂曜是否有庙旺必须有独立来源，没有来源时只写“作用强弱、触发条件、组合加减分、动态层级”。

| 对象 | 处理方式 |
|---|---|
| 主星 | 按亮度表修正承接力、稳定度和发挥方式 |
| 辅曜 | 有亮度来源才写亮度；否则写助力方式和触发条件 |
| 煞曜 | 重点写压力类型、冲突方式、修复路径和是否成格破格 |
| 杂曜 | 默认不硬套庙旺，按主题分类、同宫影响和动态触发处理 |
| 四化 | 只写来源天干、盘层、目标星和目标宫，不写庙旺 |
| 周期星 | 重点写大限、流年、流月、流日、流时层级，不反推长期命盘结论 |

## 星曜组合资料标准

组合解释必须说明“关系类型”，不能把两颗星的本体解释简单相加。

| 组合类型 | 解释重点 |
|---|---|
| 同宫 | 两颗星直接混合，判断谁主导、谁辅助、谁触发、谁修饰 |
| 对宫 | 判断外部对象、对照关系、互补、拉扯和冲突 |
| 三方四正 | 判断结构支援、资源来源、压力来源和格局成色 |
| 夹宫 | 判断左右环境如何塑造被夹宫位 |
| 会照 | 判断远端参与、间接支援、间接压力和触发强弱 |
| 四化牵动 | 判断资源、权责、名誉、牵挂分别从哪一层进入 |
| 主辅煞杂 | 主星定骨架，辅曜加支援，煞曜加压力，杂曜补细节，不能同权处理 |

组合解释必须写出：

1. 本组合的核心变化。
2. 适合落在哪类宫位。
3. 不适合落在哪类宫位。
4. 同宫时如何读。
5. 对宫时如何读。
6. 三方四正时如何读。
7. 动态盘出现时如何降权或继承。
8. 当前盘使用时需要哪些证据。

## 格局字典资料标准

格局字典分为“总字典解释”和“当前盘命中解释”两层。

| 层级 | 内容 |
|---|---|
| 总字典解释 | 解释这个格局本身是什么、核心星曜是什么、为什么成格、传统含义是什么、可能的优势和风险是什么 |
| 当前盘命中解释 | 只解释当前盘实际命中的格局，必须结合命宫、身宫、宫位、三方四正、四化、庙旺、破格和动态盘层级 |

每个格局必须有：

| 字段 | 要求 |
|---|---|
| 成格条件 | 明确需要哪些星曜、宫位、关系或盘层 |
| 破格条件 | 明确哪些煞忌、空劫、落陷、错位或关系冲突会破坏 |
| 加吉条件 | 明确哪些辅曜、禄权科、庙旺、三方支援会增强 |
| 加煞条件 | 明确哪些煞曜、化忌、空劫、刑耗会增加代价 |
| 强弱层级 | 分为核心命中、条件命中、弱命中、待校准 |
| 动态用法 | 说明原盘、大限、流年、流月、流日、流时是否允许使用 |
| 当前盘证据 | 当前盘展示时必须列出命中证据，未命中不显示 |
| 误读边界 | 不能只因一个星曜出现就宣称成格 |

## 动态盘资料标准

动态盘必须继承上层，不允许切换到流年后把大限证据删掉，也不允许流月脱离流年单独下结论。

| 盘层 | 作用 | 读法 |
|---|---|---|
| 原盘 | 长期底盘、命身基础、十二宫根基 | 默认进入页面先显示原盘 |
| 大限 | 十年阶段、阶段命宫、阶段十二宫 | 点击大限后显示大限命宫和大限十二宫，再次点击同一大限回到原盘 |
| 流年 | 年度主题、年度命宫、年度四化 | 选择流年时保留大限标记，同时叠加流年标记 |
| 流月 | 月度重点、短期触发 | 必须继承流年，不能脱离流年单独解释 |
| 流日 | 日度触发、事件提醒 | 只看短周期触发，不写长期命运结论 |
| 流时 | 时段微调、临场状态 | 只看临场变化，不放大成人生判断 |

动态盘解释必须标明“这是哪一层盘的命宫、哪一层盘的四化、哪一层盘的格局、哪一层盘的三方四正”。

## 当前盘正统分析流程

当前盘解释必须先有证据链。当前盘分析必须从证据链生成，不能直接调用总字典段落作为结论。

```txt
排盘结果
  -> 本宫星曜
  -> 宫位主题
  -> 地支空间
  -> 庙旺落陷
  -> 同宫组合
  -> 对宫关系
  -> 三方四正
  -> 左右夹宫
  -> 四化来源
  -> 格局命中与破格
  -> 动态盘继承
  -> 专题分析
  -> 当前盘结论
```

每段当前盘解释都必须能回答：

1. 结论来自哪一颗星。
2. 星落在哪个宫。
3. 宫位管什么主题。
4. 同宫有什么星。
5. 对宫有什么星。
6. 三方四正有什么支援或压力。
7. 是否有夹宫影响。
8. 是否有四化，四化来自哪一层。
9. 是否有庙旺落陷。
10. 是否命中格局或破格。
11. 属于原盘、大限、流年、流月、流日还是流时。
12. 哪些证据增强，哪些证据削弱。
13. 哪些内容需要复核。

## 专题分析输出标准

专题分析只做正统紫微斗数解释，暂不做人格化、行为映射或现代心理标签。

| 专题 | 必读宫位 | 必读关系 |
|---|---|---|
| 命身结构 | 命宫、身宫、迁移、福德 | 命迁线、三方四正、主星和格局 |
| 事业 | 官禄、财帛、迁移、命宫 | 财官线、四化、禄权科、煞忌压力 |
| 财务 | 财帛、田宅、福德、官禄 | 禄马、化禄、化忌、库地、耗曜 |
| 感情 | 夫妻、福德、命宫、迁移 | 夫妻福德线、桃花、煞忌、对宫 |
| 家庭 | 父母、兄弟、子女、田宅 | 亲缘宫线、四化牵动、夹宫 |
| 健康 | 疾厄、命宫、父母、福德 | 煞忌、空劫、动态触发和修复条件 |
| 朋友合作 | 交友、兄弟、官禄、迁移 | 资源关系、合作边界、破耗风险 |
| 迁移外部 | 迁移、命宫、官禄、财帛 | 四马地、天马、外部支援和风险 |
| 福德内在 | 福德、夫妻、命宫、疾厄 | 内在承接、长期满足、精神压力 |
| 风险修复 | 疾厄、交友、财帛、官禄、命宫 | 煞忌、破格、空劫、修复星和动态触发 |

## 来源与复核标准

数据字典必须记录理论来源，但不能把现代网站正文、现代书籍正文、截图、软件版式直接写入解释正文。
现代网站和现代书籍只作为元信息、栏目结构、主题标签和项目自有摘要来源，不作为解释正文直接入库。

| 来源类型 | 处理方式 |
|---|---|
| 公版古籍 | 可记录原文位置、篇章、术语、项目自有释义 |
| 馆藏目录 | 只记录书名、作者、版本、馆藏位置和主题标签 |
| 现代网站 | 只记录网址、标题、栏目、主题标签和项目自有摘要 |
| 现代书籍 | 暂时只存元信息和目录线索，不存正文 |
| 排盘软件参考 | 只记录差异点和功能观察，不复制界面和版式 |
| 人工校盘 | 必须脱敏，只能作为复核样例，不能直接升格为通用理论 |

## 验收标准

数据字典达到可支撑读盘的结构，必须覆盖星曜本体、星曜入宫、星曜组合、十二地支与空间组、格局成破、动态盘继承、当前盘证据链和人工校盘复核。

人格映射和行为映射不属于数据字典模块。任何新增资料都必须先进入总字典，再进入当前盘命中层，最后才能进入整盘分析。
