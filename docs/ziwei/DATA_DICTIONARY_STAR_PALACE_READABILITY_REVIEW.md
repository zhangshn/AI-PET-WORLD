## 模块定位

本文件对应 P36-H-6，用来检查星曜数据字典放进实际读盘段落时是否讲得通。
当前仍然只做紫微斗数内容资料，不做人格化映射，不做行为映射，不继续扩展采集后台。

本批先复核六颗主星和六个关键宫位：

- 六颗主星：紫微、贪狼、巨门、廉贞、武曲、破军。
- 六个宫位：命宫、夫妻宫、财帛宫、官禄宫、迁移宫、疾厄宫。

形成 36 条复核样本。每条样本都必须包含本体转宫位、同宫解释、对宫与三方四正、四化解释、动态盘边界、当前盘证据和资料不足处理。

## 每条样本必须包含

| 段落 | 作用 |
|---|---|
| 核心问题 | 先确定这颗星落到这个宫位要回答什么 |
| 本体转宫位 | 把星曜本体转成宫位议题，不停留在星曜名词 |
| 同宫解释 | 看同宫主星、辅曜、煞曜、杂曜是加强、修饰还是施压 |
| 对宫与三方四正 | 区分对宫牵引、三方支援、四正压力、夹宫会照 |
| 四化解释 | 写清谁的四化、来源天干、来源盘层、目标星和目标宫 |
| 动态盘边界 | 区分原盘、大限、流年、流月、流日、流时 |
| 当前盘证据 | 当前盘只显示真实命中的证据，不把总字典全文塞进去 |
| 可读性检查 | 检查解释是否能讲通、是否过度泛化、是否越权断语 |
| 资料不足处理 | 缺资料时降级输出或进入复核队列 |
| 复核备注 | 使用真实盘例抽查输出质量 |

## 六宫复核重点

| 宫位 | 复核重点 |
|---|---|
| 命宫 | 本人主轴、判断方式、行动入口、承接能力、命迁线 |
| 夫妻宫 | 伴侣关系、一对一合作、契约承诺、官禄对宫压力 |
| 财帛宫 | 收入结构、现金流、资源调配、福德对宫欲望 |
| 官禄宫 | 事业定位、职责承担、公共表现、财官迁是否成链 |
| 迁移宫 | 外部环境、出行迁动、异地机会、命迁线一致性 |
| 疾厄宫 | 身心承压、作息节奏、修复资源，只作提醒不作医学诊断 |

## 验收结论

本合同把“星曜解释能不能进入实际读盘”从抽象问题变成 36 条可检查样本。
这一步的重点不是继续堆资料，而是确保后续分析能按正统紫微斗数逻辑读盘：

1. 先看星曜本体。
2. 再把本体转成宫位议题。
3. 再看同宫、对宫、三方四正。
4. 再看四化来源和动态盘层级。
5. 最后只输出当前盘命中的证据。
