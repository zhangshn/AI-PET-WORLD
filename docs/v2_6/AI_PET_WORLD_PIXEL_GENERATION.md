# AI-PET-WORLD 像素自动生成

## 目标

画面根据世界事实自动生成，不依赖预先保存的静态 PNG 素材包。

## 生成链路

```txt
世界事实
-> 语义对象
-> 像素配方
-> 像素形状与颜色规则
-> Pixel Buffer
-> PixiJS 绘制
```

例如一棵树由树种、年龄、健康度、环境、世界种子和位置共同决定。相同事实与种子必须生成稳定结果，不同事实应产生可辨认的视觉变化。

## 自动验证

```txt
生成配方
-> 渲染截图
-> 程序检查尺寸、边界、碰撞、颜色和稳定性
-> AI 视觉检查轮廓、层次、遮挡和风格一致性
-> 调整配方
```

AI 并不是“盲画”。生成后必须通过程序约束和视觉检查闭环判断结果是否可用。

## 当前重点

- 对象级像素配方。
- 管家 sprite 与动作。
- 建筑和生态变化表现。
- 截图与视觉审查闭环。
