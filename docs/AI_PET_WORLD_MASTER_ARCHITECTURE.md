## 1. 项目主旨

AI-PET-WORLD 是一个自主世界游戏。

核心不是玩家手动操作角色完成任务，而是：

- 用户注册并输入出生信息。
- 项目根据紫微斗数及相关人格映射，生成管家的灵魂、性格、沟通方式、长期偏好和建设倾向。
- 管家是世界中的自主行为主体，可以参考玩家建议，但不保证服从。
- 世界由规则、资源、生态、事件和管家行为共同推进。
- 前期只有自然环境和基础资源；后续由管家自主建设住所、小镇、城市和多玩家共同世界。
- 用户主要通过游戏内手机与管家沟通。

## 2. 唯一业务主链

```txt
用户注册
-> 出生信息
-> 紫微斗数 / 人格映射
-> 管家灵魂与长期行为偏好
-> 自主世界 Runtime
-> 世界事实 World Facts
-> Scene Blueprint / Condition Mask
-> 本地自研 AI Painter 小模型
-> 候选 PNG
-> VisualJudge
-> ApprovedFrame
-> 玩家看到世界
```

## 3. 视觉系统硬边界

正式玩家世界只允许展示 `ApprovedFrame`。

以下内容永远不能作为正式世界画面：

- 程序画图。
- SVG / Canvas / HTML / CSS 渲染图。
- 调试预览图。
- 结构贴合图。
- 固定模板图。
- 占位图。
- 未过 VisualJudge 的候选图。
- 第三方在线绘图 API 直接生成的正式画面。

当前项目允许使用 PyTorch、CUDA、PIL、图像编码库等基础设施。正式图像必须由项目本地小模型推理生成，并通过项目自己的视觉审核链路。

## 4. AI Painter 正式职责

AI Painter 只负责视觉表达，不负责篡改世界事实。

```txt
后端定义世界事实
-> 后端生成结构条件 / Mask
-> 本地 AI 小模型只负责画面表达
-> VisualJudge 检查有没有乱画
-> 通过后才展示
```

Painter 可以补充草叶、碎石、水波、明暗、纹理等非重大视觉细节。

Painter 不能新增：

- 建筑。
- 角色。
- 动物。
- 道路。
- 资源。
- 事件痕迹。
- 管家行为结果。

如果世界事实中没有这些东西，AI Painter 画出来也必须被 VisualJudge 拦截。

## 6. 训练数据正式链路

```txt
原创训练 PNG
-> Source Registry：来源、授权、哈希
-> 自动结构标注
-> Blueprint v1 + 14 通道 Mask
-> Annotation Judge
-> Accepted Training Pair
-> 本地 AI Painter 训练
-> 本地模型推理 PNG
-> VisualJudge
-> ApprovedFrame
```

人工可以负责导入、抽检和决定方向，但正式训练数据不能依赖人工逐对象描边作为长期主流程。长期目标是结构先行、同源生成 Mask、机器审核。

## 8. 当前本地小模型状态

当前不是程序画图阶段，而是在训练本地自研小模型。

已经验证：

- 单样本 Direct Output 可以学出清晰像素图，说明方向可行。
- 多样本整图训练会平均化，说明不能只靠整图 RGB 回归。
- 局部 patch v1-v5 已经训练，但仍未过审。
- v5 离散像素模型边缘密度略升，但产生颜色块和结构不稳定，不能进入正式世界。
- v6 单类单样本局部训练候选通过，证明本地小模型具备学清楚局部像素的能力。
- v7 同源小批量训练指标候选通过，但发现训练样本类别错标，结果不采纳。
- v8 可见证据筛选排除了大量错标 patch，但真实样本输出仍偏糊，说明下一步要升级外观条件和小模型结构。
- v9 类别条件细节 U-Net 已完成训练和推理，但锐度、边缘密度继续下降，说明只加类别条件和更重模型不能解决真实样本平均化。
- v10 同源锁定课程训练候选通过，证明在同一 sourceId 的稳定视觉分布内，本地小模型可以生成清晰自然局部。

## 10. 当前下一步

不要继续简单堆 epoch，不要回到程序画图。

下一步是做自然局部结构任务：

1. 单类单样本局部过拟合已经候选通过，说明模型具备学习清晰局部像素的能力。
2. 当前主要问题已经收敛为多样本泛化、训练样本错标、可信训练对不足和局部边缘学习不足。
3. v9 已证明只换更重 U-Net、只加类别条件不够。v10 已证明同源锁定课程训练可恢复局部清晰度。
4. 下一步需要把 v10 从单 sourceId 扩展到多源分级课程训练，再做局部合成验证。
5. 每一轮推理结果必须进入 `generated-results` 历史页。
6. 未过 VisualJudge 不能进入 `/world`。
