0. 文档控制与统一口径
本版文档把“复杂”作为产品优势处理：复杂不是堆概念，而是把生态规律、有限资源、人格差异、自动建设、关系事件和可审计状态变化合成一套可以落地的世界引擎。
1. 产品定位
AI-PET-WORLD 不是普通宠物游戏，也不是普通建造游戏，而是一个由生命信息人格映射驱动、具备生态规则和资源循环的 AI 自主世界。玩家创建世界后，管家会作为自主管理者观察、建设、维护家园，并在长期运行中推动社区与小镇演化。
2. MVP 总目标
MVP 的目标不是一次性做完完整商业世界，而是证明核心闭环：玩家输入 -> 管家人格 -> 规则世界生成 -> 自主建设意图 -> MapDiff 世界变化 -> 只读视觉呈现 -> 日志/管家解释/P-Phone。
3. 用户体验主线
用户进入创建页，输入出生年月日、时间、视角等生命信息。
系统生成管家人格和世界 seed，但正式 UI 不显示原始命理术语。
用户进入 /world，看到一个低保真但可读的第一片家园。
管家作为自主管理者出现，解释当前世界状态和它的观察。
世界拥有资源、地貌、时间、环境与建设状态。
用户不点“建造房子”，只观察管家如何根据性格与资源形成建设计划。
Tick 推进后，系统生成 MapDiff，SafeApply 后更新家园。
世界日志、P-Phone、管家解释记录变化原因。
未来 LifeEvent 可能引入伴生生命，但不是所有用户都会进入该分支。

5. 规则生态与资源计划
MVP 可以先做简化生态，但计划书必须锁定长期方向：每个世界不是无限资源地图，而是有资源上限、消耗、恢复、新资源产生和生态压力的长期系统。
6. 自主建设计划
玩家后期建设家园、社区、小镇不是手动的。管家/居民根据性格、资源、需求、事件和环境自主建设与维护。
7. 宠物/伴生生命计划
伴生生命不再是开局默认宠物。MVP 必须保持“宠物后置”原则，并允许某些用户的管家不选择养宠物或长期等待。
8. 前台表达策略
产品前台不以“命理玄学”作为主卖点。核心表达是：生命信息驱动的专属 AI 管家与自主世界。后台可以使用东方人格模型，但正式 UI 展示结果、行为、解释和世界变化，不展示原始术语。

12. 下一轮 Codex 工作方式
后续给 Codex 的指令必须避免“尽量完成”。采用硬性模块边界、文件清单、导出入口、禁止范围、验收命令和视觉/状态验收。
13. 最终结论
AI-PET-WORLD 的优势来自复杂系统设计：规则生态世界、有限资源循环、人格驱动行为、自主建设、关系事件后置和可审计状态演化。复杂不是问题，复杂是护城河；但必须把复杂落实为明确数据结构、规则、模块、验收和可见结果。
14. 版本范围与商业化前置判断
MVP v2.0 不是最终商业版，而是验证核心世界闭环的工程产品。它必须让用户看懂“这是我的世界在自己运行”，但不需要一次性完成多用户小镇、真实经济和完整宠物生态。

17. 下一轮 Codex Prompt 设计原则
每条 prompt 必须明确当前模块，不再让 Codex 自行猜“剩余所有内容”。
每条 prompt 必须列允许修改文件和禁止修改文件。
每条 prompt 必须有硬性导出入口和验收命令。
每条 prompt 必须要求最终回复表格：已完成、未完成、改了哪些、不改哪些、如何验证。
涉及世界事实的模块必须要求 MapDiff/SafeApply，不允许 UI 直接写对象。
涉及视觉的模块必须强调 FormalVisualModel 只读，不允许为了好看创造事实。
涉及宠物/伴生体的模块必须强调后置，不能默认生成宠物或宠物床。
Prompt skeleton:
当前模块：WORLD-GEN-04
目标：非固定布局生成重构
允许修改：src/world/generation/*, src/world/placement/* audit only...
禁止修改：src/app/world/*, public/*, package.json...
必须导出：buildNonFixedWorldLayoutCandidates, auditLayoutVariation...
必须验证：lint, tsc, build, smoke scenario screenshots/fingerprints
18. 产品展示脚本
用于后续录屏或讲解时的产品表达，不提命理玄学，以“生命信息驱动人格映射和自主世界”表达。
这是一个会自己运行的 AI 世界，玩家不是直接操作建造的人。
你输入生命信息后，系统生成一个代表你的管家人格。
管家会根据自己的性格、资源和环境，整理、维护和建设家园。
这个世界的资源是有限的，会消耗、恢复，也会因为环境产生新变化。
家园后续可能连接成社区，小镇也会由世界内部需求自然形成。
伴生生命不是默认宠物，而是未来可能出现的关系事件。
所有画面都来自世界状态容器，不是前端画死的假图。
