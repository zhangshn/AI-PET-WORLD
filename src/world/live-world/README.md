# Live World Module

This module owns the first executable data contract for the AI-PET-WORLD living world.

Current scope:

- World, chunk, tile, entity, lifecycle, collision, visual input, candidate, review, and sample types.
- MVP placement rules.
- POC-0 preparation for one 32x32 chunk.

Out of scope for P0:

- Calling AI Painter.
- Rendering `/world`.
- Generating the full 5x5 world.
- Automatic visual judging.
- Training-loop orchestration.
