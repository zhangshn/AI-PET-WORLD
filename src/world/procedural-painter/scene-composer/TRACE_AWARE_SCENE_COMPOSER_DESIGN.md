# Trace-aware Scene Composer Design

## Purpose

Scene Composer uses `traceFacts`, `traceShape`, and `traceDensity` together, but only `traceFacts` are trace facts. `traceDensity` is a composition signal and must not create long-used area by itself.

## Layered Influence

Trace influence is separated into:

- movement influence
- spatial_use influence
- ecology influence

Long-used area can only be generated by movement trace. If there is no movement trace fact, Scene Composer must not generate long-used area tiles.

`spatial_use` is not movement. It can create local use pressure, lighter grass, or object-density changes, but it must not become a long-used movement area.

`ecology` is not movement. It can create ecology transition and grass-density changes, but it must not become a long-used movement area.

## Compatibility

The renderer still receives legacy visual tile kinds:

- `"path"` means deprecated renderer compatibility for long-used area tile.
- `"edge"` means deprecated renderer compatibility for trace edge / ecology transition tile.

These names are not formal business concepts and must not be expanded into a fixed movement network.

## Boundary

M4 only changes scene composition. It does not implement final trace visuals. M5 can express trampling, exposed soil, recovery, and other visual details.
