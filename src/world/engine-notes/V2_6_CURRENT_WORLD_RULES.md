# AI-PET-WORLD V2.6 当前世界规则红线

本文用于防止旧设定、旧聊天摘要、旧测试口径污染当前 V2.6 正式设计。

## 优先级

当前项目所有正式开发按以下优先级执行：

1. 用户当前明确指令
2. V2.6 三份正式主文档
3. 当前 Git 代码与当前验收文档
4. 历史讨论，仅可作为背景，不可覆盖当前定稿

## 当前正式口径

AI-PET-WORLD V2.6 的正式世界不是传统宠物养成游戏，也不是玩家直接控制世界的游戏。

当前正式口径：

- 玩家是世界源头，不是直接操作者
- 管家是玩家生命信息生成的自主意识管理者
- 宠物是独立自主生命，不是玩家指令对象
- 世界由世界规则、环境状态、生命行为、关系与时间推进共同演化
- 主世界展示应呈现结果、环境、行为、生活痕迹与解释层，而不是暴露底层测试参数

## 废弃旧设定红线

以下内容不得进入正式设计、正式页面、正式文档或正式代码链路：

- 不使用孵化器作为当前正式世界初始概念
- 不使用胚胎默认链路作为当前正式世界初始概念
- 不使用候选宠物驱动作为当前正式世界初始概念
- 不让宠物默认进入世界
- 不把旧版宠物出生链路混入当前主世界展示

如果测试页、历史文件或旧聊天摘要出现相关概念，只能视为历史废弃内容，不得作为当前功能依据。

## Scene Composer 当前边界

`/world-debug/pixel-scene-composer` 是像素世界组合算法测试页，不是正式主世界。

当前测试页只验证：

- 地面 tile
- 道路方案
- 道路边缘生态
- 草、树、花、石头、灌木组合
- y-sort 与层级
- 湿度和装饰密度的视觉影响

它不能决定正式世界里真实存在什么。

正式世界对象必须来自未来的 WorldState / HomeMapState / worldEngine 等事实层。

## 主页面接入规则

任何视觉算法进入 `/world` 主页面前，必须满足：

1. 不能直接把测试 SVG 当正式世界
2. 不能由 UI 自己创造正式世界事实
3. 不能把调试参数暴露成正式世界规则
4. 必须通过正式 gateway / schema 接收世界事实
5. 必须先通过 world-debug 验证，再进入主页面候选

## 当前下一步

当前阶段的下一步不是接入主页面，而是继续拆分正式模块：

- scene-composer
- terrain painter

拆分完成后，再做正式世界事实接入验证。
