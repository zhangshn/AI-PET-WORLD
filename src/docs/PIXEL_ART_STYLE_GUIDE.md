# AI-PET-WORLD 像素美术风格规范 v0.1

## 1. 目标

AI-PET-WORLD 的像素风不是普通色块。

目标是参考成熟像素游戏的可读性、比例感、统一色彩、对象轮廓和场景层次，但不照搬任何具体游戏资产。

参考原则：

- 清晰轮廓
- 低色数
- 统一光源
- 对象比例稳定
- 地图网格清晰
- 色彩语义一致
- 角色与环境分离清楚
- 小尺寸也能识别对象

## 2. 基础规格

- 世界网格：16px。
- 像素绘制单位：4px。
- 宠物基础尺寸：32x32 或 40x40。
- 管家基础尺寸：32x48 或 40x56。
- 树木：32x48 或 40x56。
- 临时住所：64x48。
- 基础小屋：80x64。
- 临时领养中心：96x64。
- 大型领养中心未来扩展。

## 3. 色彩语义

- 草地：绿色系。
- 泥地 / 路径：棕色系。
- 木头：暖棕。
- 墙体：米色 / 灰褐。
- 屋顶：深棕 / 暖棕。
- 宠物：主色 + 特征色，由紫微匹配结果影响。
- 管家：肤色、衣服色、头发色要区分，受紫微人格视觉 DNA 影响。
- 交互设施：稍亮。
- 逻辑点位：开发模式蓝灰色。
- 光效：浅黄色。
- 阴影：半透明深灰。

## 4. 对象比例

宠物不能像小方块。

管家不能像普通色块。

房屋不能一开始就是完整大房子。

当前房屋阶段要区分：

- 临时住所
- 基础小屋
- 稳定家园

## 5. 场景规则

场景应该由 Prefab 组成。Primitive 不能直接拼最终场景。

世界要表现：

- 土地
- 草地
- 树木
- 路径
- 照护点
- 临时住所
- 基础小屋
- 临时领养中心 / 领养抵达点
- 管家
- 宠物
