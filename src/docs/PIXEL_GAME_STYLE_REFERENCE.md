# AI-PET-WORLD 像素游戏风格参考原则 v0.1

## 1. 定位

AI-PET-WORLD 的像素视觉不是网页插画，也不是普通 UI 色块。

它要服务于这条核心生成链路：

```txt
ZiweiProbabilityProfile
↓
PreferenceProfile
↓
VisualDNA
↓
SpriteVariant
↓
PrefabVariant
↓
SceneLayout
```

不同玩家因为紫微斗数结构不同，会生成不同管家形象、宠物类型、颜色倾向、家园风格和场景方向。

## 2. 参考原则

可以参考成熟农场 / 生活类像素游戏的通用视觉原则，例如清晰轮廓、统一 tile 网格、小尺寸可读性和稳定比例。

但必须注意：

- 不复制任何具体游戏素材。
- 不复刻星露谷或其他游戏资产。
- 不使用外部图片。
- 不引入版权素材。
- 不把参考对象当作直接素材来源。

AI-PET-WORLD 只参考成熟像素游戏的设计原则，不复制图形。

## 3. 画面原则

像素游戏风格基准应遵守：

- 基础网格：16px。
- 主要像素绘制单位：4px 或 8px。
- 地面必须 tile 化，不能像一整块网页背景。
- 对象必须有深色轮廓，便于小尺寸识别。
- 色彩低色数，避免网页渐变和柔光堆叠。
- 统一光源，避免每个物件像单独 UI 图标。
- 房屋、树、管家、宠物、照护角之间比例稳定。
- 场景像游戏地图切片，不像后台 dashboard。

## 4. 对象规格

MVP 视觉样板建议尺寸：

| 对象 | 建议尺寸 |
|---|---:|
| 地面 tile | 16x16 |
| 宠物 sprite | 32x32 |
| 管家 sprite | 32x48 |
| 树木 sprite | 32x48 或 48x64 |
| 照护角 prefab | 80x48 |
| 临时住所 prefab | 80x64 |
| 基础小屋 prefab | 96x80 |
| 临时领养中心 prefab | 96x64 或更大 |

## 5. 紫微视觉差异

6 个 MVP 紫微视觉方向必须看得出差异：

### structured_builder / 秩序建设型

- 路径更直。
- 地基更整齐。
- 小屋更方正。
- 储物和建设感更明显。
- 色彩偏清晰、稳定、结构化。

### warm_caretaker / 温暖照护型

- 暖色更明显。
- 宠物床、食物碗、水碗更突出。
- 宠物更圆润亲近。
- 照护角优先出现。

### protective_keeper / 边界守护型

- 围栏、边界、安全角落更明显。
- 小屋有加固感。
- 树和灌木形成保护结构。
- 观察点和防护感更强。

### aesthetic_organizer / 审美整理型

- 花园、装饰、窗光更明显。
- 小屋更有装饰感。
- 色彩更明亮。
- 宠物更活泼。

### quiet_maintainer / 安静维护型

- 低饱和。
- 树荫和安静区域更明显。
- 装饰少。
- 小屋低调稳定。
- 宠物更像安静观察型。

### adaptive_planner / 适应规划型

- 混合风格。
- 路径和设施布局更灵活。
- 不极端偏向单一风格。
- 根据资源和宠物状态动态调整。

## 6. 当前阶段边界

当前 `/visual-variant-test` 仍然是视觉基准测试页，不是最终游戏画面。

本阶段目标是验证：

```txt
不同紫微概率结果
↓
不同喜好画像
↓
不同 VisualDNA
↓
不同像素世界方向
```

下一阶段如果继续提升视觉质量，应进入 Sprite Sheet 规格，而不是继续用 CSS 硬画最终素材。
