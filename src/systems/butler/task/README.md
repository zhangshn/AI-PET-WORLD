# butler/task

当前目录属于管家系统的既有任务判断区，阶段性归入第 7 层：自主驱动层。

## 当前负责

这里当前承接既有管家任务选择逻辑。

当前任务判断用于帮助管家在观察孵化器、照看宠物、建设家园、提供机会、保持等待等方向之间形成任务倾向。

## 当前不能做

- 不能替宠物做决定
- 不能把任务判断写成固定脚本
- 不能直接写 UI 或 P-Phone 展示
- 不能把世界事件自动转为管家消息
- 不能继续无限堆复杂业务判断

## 后续扩展方向

- 逐步拆分为 intention、education、message-decision 和 behavior 的输入
- 保留任务判断 trace
- 将复杂判断迁入更明确的 layer gateway
- 最终让 task 成为薄的任务倾向入口或兼容层
