# butler/intention

当前目录属于第 7 层：自主驱动层。

## 当前负责

这里未来负责管家意图形成。

管家不是普通 NPC，也不是固定任务机。管家是用户生命数据映射 / 平行世界人格投射，拥有自主判断。

本目录未来负责：

- 管家对当前世界状态的理解
- 管家对宠物状态的解释
- 管家对玩家互动的解释
- 管家是否靠近、等待、保护、记录、解释、提供机会的意图判断
- 管家是否暂时不行动的判断

这一层回答的问题是：

```txt
管家此刻为什么想做某件事，或者为什么选择不做？
```

## 当前不能做

- 不能直接执行行为
- 不能替宠物做决定
- 不能把玩家输入写成直接控制指令
- 不能写 P-Phone UI
- 不能把系统事件自动变成管家消息
- 不能绕过记忆 / 关系和教育边界

## 后续扩展方向

- 意图生成
- 意图优先级
- 意图解释
- 意图冷却
- 保持距离 / 保护性回应判断
