# butler/behavior

当前目录属于第 8 层：行为执行层。

## 当前负责

这里未来负责把管家已经形成的意图转为可执行行为。

管家行为执行不是意图来源，也不是消息决策来源。它只承接上层已经形成的意图或判断，并表达为建设、整理、观察、解释、保护性回应、提供机会或联系玩家等行为。

## 当前不能做

- 不能写管家意图来源
- 不能写教育原则
- 不能写消息决策
- 不能替宠物做决定
- 不能直接决定宠物 action
- 不能把玩家输入写成直接控制管家的命令

## 后续扩展方向

- 行为执行 gateway
- 行为稳定与冷却
- 行为结果回写
- 机会创建执行
- 解释 / 保护 / 环境管理类行为执行
