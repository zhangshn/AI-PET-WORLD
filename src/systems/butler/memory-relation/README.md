# butler/memory-relation

当前目录属于第 5 层：记忆 / 关系层。

## 当前负责

这里负责管家自身的长期记忆、经验材料，以及管家与宠物之间的关系状态。

管家创建时有先天人格，但没有世界经历记忆。世界经历需要在运行中逐步形成，不能在创建时伪造为已经发生过的生活记忆。

本目录当前承接：

- 管家记忆结构
- 管家和宠物的关系状态
- 管家对机会反馈、任务判断、宠物反应的经验材料记录
- 可被后续 intention / education / message-decision 读取的关系线索

## 当前不能做

- 不能把 memory 当 learning
- 不能直接控制管家行为
- 不能替宠物写入学习结果
- 不能把系统日志当成管家记忆
- 不能绕过管家自主判断直接触发 P-Phone 消息

## 后续扩展方向

- 关系记忆 gateway
- 管家经验摘要
- 管家照看方式调整依据
- 管家与玩家互动记忆
- 管家与宠物边界经验记录
