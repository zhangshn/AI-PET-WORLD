# butler/education

当前目录属于管家主体系统中的教育职责区，服务于第 7 层自主驱动与第 8 层行为执行之间的判断边界。

## 当前负责

这里未来负责管家对幼儿期宠物的照看、教育、引导、保护判断。

宠物出生时没有生活记忆。管家可以提供机会、保持距离、保护性回应、记录经验、调整照看方式，但不能替宠物做决定。

本目录未来负责：

- 幼儿期宠物照看原则
- 食物、休息、距离、安全边界的教育机会判断
- 管家是否应该靠近、等待、解释或保护
- 管家如何根据宠物反应调整照看方式
- 教育相关经验如何进入 memory-relation

## 当前不能做

- 不能替宠物吃、睡、靠近、信任或学习
- 不能直接写入宠物学习结果
- 不能把教育写成对宠物行为的直接控制
- 不能写 UI 消息展示
- 不能写世界 tick 细节

## 后续扩展方向

- 教育机会判断
- 保护性回应
- 距离控制
- 幼儿期解释策略
- 教育结果记录
- education gateway
