## 1. 项目一句话

AI-PET-WORLD 是一个以“管家自主灵魂”和“世界自主生成”为核心的长期运行游戏。

玩家不是直接控制角色去完成固定任务，而是通过游戏内手机与自己的管家沟通。管家有自己的性格、动机、判断和行动倾向，可以参考玩家建议，但不保证服从。世界由规则、资源、生态、事件、管家行为和后续多玩家管家共同建设持续推进。

## 2. 核心业务主线

```txt
用户注册
-> 输入出生年月日
-> 紫微斗数 / 人格映射
-> 管家灵魂、性格、沟通方式、长期偏好
-> 自主世界 Runtime
-> 世界事实 World Facts
-> Scene Blueprint / Condition Mask
-> 本地自研 AI Painter 小模型
-> 候选视觉输出
-> VisualJudge 审核
-> ApprovedFrame / RuntimeFrame
-> 玩家看到世界
```

关键原则：

| 原则 | 说明 |
|---|---|
| 世界事实优先 | 视觉系统只表达事实，不能篡改事实 |
| 管家自主 | 玩家建议不是命令，管家可以不同意 |
| 世界自主 | 自然、生态、事件和建设都由规则与行为推进 |
| 审核后展示 | 未通过 VisualJudge 和 ApprovedFrame 的内容不能给玩家看 |
| 本地自研视觉 | 当前 AI Painter 走本地自研小模型，不接第三方在线绘图 API |

## 3. 总体架构表

| 层级 | 模块 | 职责 | 当前状态 |
|---|---|---|---|
| 用户层 | 注册 / 出生信息 / 手机沟通 | 玩家进入世界、提供命盘输入、和管家沟通 | 业务规则已固定 |
| 灵魂层 | 紫微斗数 / 人格映射 / 管家 profile | 生成管家性格、动机、沟通方式和建设倾向 | 方向已固定 |
| Runtime 层 | world runtime / tick / construction / trace | 维护世界事实，不负责画面美化 | 主链已成型 |
| 事实层 | World Facts / sourceFactIds | 作为视觉系统唯一事实来源 | 当前自然家园使用中 |
| 结构层 | Scene Blueprint / Condition Mask | 把世界事实转成视觉结构约束 | 当前主线 |
| 模型层 | 本地 AI Painter 小模型 | 根据结构条件生成候选画面 | 当前主线 |
| 审核层 | VisualJudge VJ-0 / VJ-1 / VJ-2 | 审核事实、质量、风格、语义和状态一致性 | VJ-0 完成，VJ-1 进行中，VJ-2 未完成 |
| 展示层 | ApprovedFrame / RuntimeFrame / `/world` | 只展示过审正式画面 | ApprovedFrame 未完成 |
| 训练运营层 | 训练记录 / 失败图 / 资源账本 / 时间戳 | 保存所有训练结果和失败原因 | 已接通，继续强化 |
| 后续动态层 | VisualUnit / 人物 / 建筑 / 动态状态帧 | 把静态世界扩展成活的游戏世界 | 后置 |

## 4. 游戏长期模块

| 模块 | 目标 |
|---|---|
| 用户与命盘 | 用户出生信息进入人格映射 |
| 管家灵魂 | 管家的性格、偏好、沟通方式、建设倾向 |
| 自主 Runtime | 世界 tick、事件、资源、生态、建设计划持续推进 |
| 世界事实系统 | 所有视觉内容都必须来源于事实 |
| AI Painter | 把世界事实转成候选画面 |
| VisualJudge | 判断画面是否符合事实、质量、风格和状态 |
| ApprovedFrame / RuntimeFrame | 通过审核后才可展示 |
| 自然世界 | 草地、水体、水岸、树、石、花草、深度 |
| 管家 / 人物 | 后续训练体型、动作、状态和交互 |
| 建筑 / 设施 | 后续训练地基、墙体、屋顶、内部空间、设施 |
| 动态状态 | 后续训练水流、树叶、天气、动物、昆虫、状态帧 |
| 小镇 / 城市 | 后续由多玩家管家共同建设 |

## 5. 当前 MVP 范围

当前 MVP 不做完整游戏全部内容，先完成视觉底座的第一条正式闭环：

```txt
纯自然家园世界事实
-> 本地 AI Painter 小模型生成候选图
-> VisualJudge 审核
-> 第一张自然家园 ApprovedFrame
-> /world 展示正式画面
```

当前允许内容：

| 类型 | 说明 |
|---|---|
| 草地 | 自然家园底色和地表变化 |
| 水体 | 河流、池塘、水面 |
| 水岸 | 水体与地面交界 |
| 自然小路 | 土路、小径，不是城市道路 |
| 树木 | 自然树、森林边界 |
| 岩石 | 石块、山石、岸边石 |
| 花草灌木 | 细节和自然层次 |
| 空间深度 | 前中远景、遮挡、层次 |

当前禁止混入：

| 类型 | 处理 |
|---|---|
| 建筑 / 房屋 / 临时住所 | 后续建筑 VisualUnit |
| 地基 / 墙体 / 屋顶 | 后续建设阶段 VisualUnit |
| 施工材料 | 后续建设系统 |
| 管家 / 人物 | 后续人物 VisualUnit |
| 动物 / 昆虫 | 后续生态和动态单元 |
| 小镇 / 城市 | 后续长期世界扩展 |

## 6. 正式展示边界

正式玩家世界只允许展示 `ApprovedFrame` 或后续经过同级审核的 `RuntimeFrame`。

以下内容不能作为正式世界画面：

- 程序画图。
- SVG / Canvas / HTML / CSS 渲染图。
- 调试预览图。
- 结构贴合图。
- 固定模板图。
- 占位图。
- 未过 VisualJudge 的候选图。
- 第三方在线绘图 API 直接生成的正式画面。

## 8. 当前禁止事项

| 禁止事项 | 原因 |
|---|---|
| 把程序画图当作正式画面 | 程序图只能调试结构，不能代表 AI Painter 结果 |
| 把候选图直接放进 `/world` | 未过审图不能展示给玩家 |
| 提前做人、建筑、动态、小镇 | 当前自然家园小模型和 ApprovedFrame 未完成 |
| 临时改变验收标准 | 会造成主线漂移 |
| 使用第三方在线绘图 API 做正式画面 | 当前路线是本地自研小模型 |
| 删除失败图和打回图 | 失败数据要用于训练反馈和审计 |
