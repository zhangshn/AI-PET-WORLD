## 项目一句话

AI-PET-WORLD 是一个以“管家自主灵魂”和“世界自主生成”为核心的长期运行游戏。

玩家不是直接控制角色完成固定任务，而是通过游戏内手机与自己的管家沟通。管家有自己的性格、动机、判断和行动倾向，可以参考玩家建议，但不保证服从。世界由规则、资源、生态、事件、管家行为和未来多玩家管家共同建设持续推进。

## 当前正式主线

```txt
用户注册
-> 输入出生年月日
-> 紫微斗数 / 人格映射
-> 管家灵魂、性格、沟通方式、长期偏好
-> 自主世界 Runtime
-> 世界事实 World Facts
-> Scene Blueprint / Condition Mask
-> 本地自研 AI Painter 小模型
-> 候选视觉输出
-> VisualJudge 审核
-> ApprovedFrame / RuntimeFrame
-> 玩家看到世界
```

当前正在执行的主线是：

```txt
自然家园小模型训练
-> 自然家园候选图自动归档
-> VisualJudge 强化
-> 通过后生成自然家园 ApprovedFrame
```

当前不是继续扩展 VisualUnit，也不是做人物、管家、建筑、动态状态帧或小镇城市。它们全部后置，不能抢当前主线。

## 视觉生成架构摘要

后期游戏不是靠一张巨大 PNG 运行，也不是把训练候选图直接贴到 `/world`。

正式方向是：

```txt
世界事实
-> 结构条件 / Mask
-> 本地自研 AI Painter 生成视觉表达
-> VisualJudge 审核
-> ApprovedFrame / RuntimeFrame
-> Runtime 按地形、物件、状态层组合
-> 玩家看到可运行世界
```

AI Painter 训练分成两条线：

| 训练线 | 作用 | 是否当前主线 |
|---|---|---:|
| 完整自然家园训练 | 学习整体构图、自然区域关系、世界画面气质 | 是 |
| 局部视觉单元训练 | 学习树、水、草、石、人物、建筑、状态帧等可复用单元 | 后置 |

当前先完成“完整自然家园训练 + VisualJudge + 第一张正式自然家园 ApprovedFrame”。局部视觉单元和动态合成要等主线达标后再推进。

## 固定原则

| 原则 | 说明 |
|---|---|
| 世界事实优先 | 视觉系统只表达事实，不能篡改事实 |
| 管家自主 | 玩家建议不是命令，管家可以不同意 |
| 世界自主 | 自然、生态、事件和建设由规则与行为推进 |
| 没审核不展示 | 未通过 VisualJudge 和 ApprovedFrame 的内容不能展示给玩家 |
| `/world` 只放主世界 | `/world` 不是训练预览页；局部图、crop 图、候选图、失败图都不能放进主页面 |
| 本地自研视觉 | 当前 AI Painter 走本地自研小模型，不接第三方在线绘图 API |
| 候选不是正式 | 候选图、训练图、失败图、调试图都不是正式世界图 |
